# BED005: Blank line between data lines

| | |
|---|---|
| Name | `blank-line` |
| Format | BED |
| Level | `warning` by default, `info` with `--strict` |
| Source | BED v1.0 §1.4.2 |

The specification allows blank lines anywhere, but not every parser follows it: a reader may stop at the first empty line, or report a malformed record. A line that looks empty but contains spaces or tabs is worse, because tab-based parsers see fields in it. Delete blank lines.

## Example

```text
chr1→1000→5000

chr1→7000→7250
```

biolint reports:

```text
warning[BED005]: blank line inside the file
 --> example.bed:2:1
  |
2 | 
  | ^
  = help: delete the line: some tools stop reading at the first blank line
  = spec: BED v1.0 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED005`, or check only this rule with `--select BED005`.
