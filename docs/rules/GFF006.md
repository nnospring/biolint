# GFF006: Two ##sequence-region lines for the same sequence

| | |
|---|---|
| Name | `sequence-region-duplicate` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Other Syntax: ##sequence-region |

Only one `##sequence-region` directive may be given for a sequence. Two of them usually come from concatenating files; which one a parser keeps is not defined. biolint checks features against the first.

## Example

```text
##gff-version 3
##sequence-region chr1 1 50000
##sequence-region chr1 1 60000
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
warning[GFF006]: a second `##sequence-region` for `chr1`
 --> example.gff3:3:1
  |
3 | ##sequence-region chr1 1 60000
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: keep one directive per sequence
  = note: first given on line 2 as 1-50000
  = spec: GFF3 1.26, Other Syntax: ##sequence-region
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF006`, or check only this rule with `--select GFF006`.
