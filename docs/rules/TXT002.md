# TXT002: File starts with a UTF-8 byte-order mark

| | |
|---|---|
| Name | `utf8-bom` |
| Format | Any format |
| Level | `warning` |
| Fixable | yes, with `biolint --fix` |

The three bytes EF BB BF sit in front of the first character. They are invisible in editors, but parsers see them as part of the first field, so `##fileformat`, `>` or `@HD` no longer match. Usually added by Windows editors or Excel "CSV UTF-8".

## Configuration

Silence it with `--ignore TXT002`, or check only this rule with `--select TXT002`.
