# VCF201: Wrong number of columns in a record

| | |
|---|---|
| Name | `column-count` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6 |

Every record has the same number of tab-separated columns as the header line. Too few usually means spaces were used instead of tabs or the line was truncated; too many means a tab inside a value or a trailing tab.

## Example

The record is separated by spaces:

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1 100 . A T . . .
```

biolint reports:

```text
error[VCF201]: record has 1 column but the header has 8
 --> example.vcf:3:18
  |
3 | 1 100 . A T . . .
  |                  ^
  = help: the fields seem to be separated by spaces; VCF columns must be separated by single tab characters
  = spec: VCF 4.3 §1.6
```

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.
```

biolint reports:

```text
error[VCF201]: record has 7 columns but the header has 8
 --> example.vcf:3:16
  |
3 | 1→100→.→A→T→.→.
  |                ^
  = help: the line may be truncated, or a tab was replaced by spaces
  = spec: VCF 4.3 §1.6
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF201`, or check only this rule with `--select VCF201`.
