# BED037: thickStart or thickEnd lies outside the feature

| | |
|---|---|
| Name | `thick-out-of-range` |
| Format | BED |
| Level | `warning` by default, `error` with `--strict` |
| Source | BED v1.0 §1.8 |

The thick part must lie inside the feature: chromStart ≤ thickStart ≤ thickEnd ≤ chromEnd. Positions are absolute chromosome coordinates, not offsets from the start. Genome browsers draw such features wrongly and validating converters reject them. When there is no thick part, set both to chromStart.

## Example

```text
chr1→1000→5000→geneA→0→+→1200→4800
chr1→7000→7250→geneB→0→-→6900→7250
```

biolint reports:

```text
warning[BED037]: thickStart `6900` is before chromStart `7000`
 --> example.bed:2:26
  |
2 | chr1→7000→7250→geneB→0→-→6900→7250
  |                          ^^^^
  = help: use `7000` (chromStart) when there is no thick part
  = note: 8 fields per line, all read as standard fields (BED8, inferred from line 1); if column 7 is a custom field instead, declare it with `--option bed.type=bed6+2`
  = spec: BED v1.0 §1.8
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED037`, or check only this rule with `--select BED037`.
