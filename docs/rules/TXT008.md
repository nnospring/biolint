# TXT008: Look-alike Unicode character where ASCII was meant

| | |
|---|---|
| Name | `suspicious-unicode` |
| Format | Any format |
| Level | `warning` |
| Fixable | yes, with `biolint --fix` |

A character that looks like ordinary punctuation or a space but is a different code point: curly quotes and long dashes from word processors, no-break and zero-width spaces from web pages and PDFs, or full-width punctuation typed with a CJK input method. Parsers compare bytes, so `；` is not `;` and `”` does not close a `"`.

## Example

No-break space after the identifier:

```text
>seq1⍽sample A
ACGT
```

biolint reports:

```text
warning[TXT008]: U+00A0 NO-BREAK SPACE is not the ASCII character it looks like
 --> example.fasta:1:6
  |
1 | >seq1␣sample A
  |      ^
  = help: replace it with an ordinary space
  = fix: Replace U+00A0 with ASCII (--fix)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore TXT008`, or check only this rule with `--select TXT008`.
