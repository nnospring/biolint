# SAM113: MAPQ is not an integer from 0 to 255

| | |
|---|---|
| Name | `mapq-invalid` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

Mapping quality is a whole number from 0 to 255, where 255 means "not available". Write 0 or 255 rather than `*` or a decimal when the aligner gives no value.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→256→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM113]: MAPQ 256 is larger than 255
 --> example.sam:3:14
  |
3 | r1→0→chr1→10→256→5M→*→0→0→ACGTA→IIIII
  |              ^^^
  = help: mapping quality is capped at 254; 255 means "not available"
  = spec: SAM v1 §1.4
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→*→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM113]: MAPQ `*` is not an integer from 0 to 255
 --> example.sam:3:14
  |
3 | r1→0→chr1→10→*→5M→*→0→0→ACGTA→IIIII
  |              ^
  = help: `*` is the placeholder of text fields; MAPQ is a number and its placeholder is `0` (or 255 for "not available")
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM113`, or check only this rule with `--select SAM113`.
