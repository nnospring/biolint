# SAM018: @PG PP does not point to another @PG line

| | |
|---|---|
| Name | `pg-previous-unknown` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

`PP` names the `ID` of the program that ran before this one, which makes a chain recording the processing history. The value must be the `ID` of a different `@PG` line, anywhere in the header. A dangling or self-referring `PP` breaks the chain; samtools warns about it.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@PG→ID:samtools→PN:samtools→PP:bwa
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM018]: `PP:bwa` does not match the ID of any @PG line
 --> example.sam:3
  = help: add the @PG line of the earlier program, or delete this `PP` field
  = spec: SAM v1 §1.3
```

A program cannot be its own predecessor:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@PG→ID:bwa→PN:bwa→PP:bwa
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM018]: `PP:bwa` points at its own @PG line
 --> example.sam:3:22
  |
3 | @PG→ID:bwa→PN:bwa→PP:bwa
  |                      ^^^
  = help: PP names the program that ran before this one; delete it on the first step of the chain
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@PG→ID:samtools→PN:samtools→PP:bwa
@PG→ID:bwa→PN:bwa
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

## Configuration

Silence it with `--ignore SAM018`, or check only this rule with `--select SAM018`.
