# GFF303: Parent refers to an ID that is not in the file

| | |
|---|---|
| Name | `parent-unresolved` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Parent (part_of) Relationships |

A `Parent` value must be the `ID` of another feature. The parent may come later in the file, so this is decided at the end of the file or at a `###` line, which declares that everything above it is complete. An exon whose transcript is missing cannot be assembled into a gene model, and GenomeTools stops with "was not defined". The parent is usually lost by filtering lines with `grep` or by subsetting a region; a typo or a difference in case (`Gene1` and `gene1`) is the other cause.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene01
```

biolint reports:

```text
error[GFF303]: Parent `gene01` is not the ID of any feature in the file
 --> example.gff3:3
  = help: check the spelling and the case of the ID; if the file was filtered or cut from a larger one, the parent line was probably removed
  = spec: GFF3 1.26, Parent (part_of) Relationships
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
chr1→example→exon→2100→2600→.→+→.→Parent=tx1
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
chr1→example→gene→2100→7400→.→+→.→ID=gene1
###
chr1→example→gene→12000→15000→.→-→.→ID=gene2
```

## Configuration

Silence it with `--ignore GFF303`, or check only this rule with `--select GFF303`.
