# VCF103: FORMAT column without samples, or samples without FORMAT

| | |
|---|---|
| Name | `header-format-samples` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.5 |

If the file carries genotypes, the ninth column is `FORMAT` and at least one sample name follows it. A lone `FORMAT` column or sample names directly after `INFO` are both invalid.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT
1→100→.→A→T→.→.→.→GT
```

biolint reports:

```text
error[VCF103]: the header has a FORMAT column but no sample columns
 --> example.vcf:2:40
  |
2 | #CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT
  |                                        ^^^^^^
  = help: add the sample names after FORMAT, or remove the FORMAT column from header and records
  = spec: VCF 4.3 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF103`, or check only this rule with `--select VCF103`.
