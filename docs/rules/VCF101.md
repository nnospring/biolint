# VCF101: Column header line (#CHROM ...) is missing

| | |
|---|---|
| Name | `header-missing` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.5 |

The `#CHROM POS ID REF ALT QUAL FILTER INFO` line is mandatory and must come before the first record. Without it the number and names of samples are unknown.

## Example

```text
##fileformat=VCFv4.3
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF101]: a record appears before any `#CHROM` column header line
 --> example.vcf:2:1
  |
2 | 1→100→.→A→T→.→.→.
  | ^^^^^^^^^^^^^^^^^
  = help: add a tab-separated line `#CHROM POS ID REF ALT QUAL FILTER INFO` (plus `FORMAT` and sample names) above the first record
  = spec: VCF 4.3 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF101`, or check only this rule with `--select VCF101`.
