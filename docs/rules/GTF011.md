# GTF011: Feature type differs from a GTF type only in capitalisation

| | |
|---|---|
| Name | `feature-case` |
| Format | GTF |
| Level | `warning` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: <feature> |

Feature types are case-sensitive: `CDS`, `start_codon`, `stop_codon`, `exon`, `5UTR`, `3UTR`, `inter`, `inter_CNS`, `intron_CNS`. A program that looks for `exon` lines finds none in a file that says `Exon`, and reports that the annotation is empty or that no reads were assigned.

## Example

```text
chr1→example→Exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
warning[GTF011]: feature type `Exon` must be written `exon`
 --> example.gtf:1:14
  |
1 | chr1→example→Exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
  |              ^^^^
  = help: feature types are case-sensitive; tools that select `exon` lines skip this one
  = spec: GTF 2.2, GTF Field Definitions: <feature>
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF011`, or check only this rule with `--select GTF011`.
