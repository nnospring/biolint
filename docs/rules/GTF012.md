# GTF012: Feature type is not defined by GTF 2.2

| | |
|---|---|
| Name | `feature-nonstandard` |
| Format | GTF |
| Level | `off` by default, `warning` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: <feature> |

GTF 2.2 defines nine feature types (`CDS`, `start_codon`, `stop_codon`, `exon`, `5UTR`, `3UTR`, `inter`, `inter_CNS`, `intron_CNS`) and says every other type is ignored. Ensembl and GENCODE files add `gene`, `transcript`, `five_prime_utr`, `three_prime_utr`, `UTR` and `Selenocysteine` lines, and the tools in common use expect or accept them, so this is reported only in the strict profile, as a warning.

## Example

```text
chr1→example→transcript→1200→2100→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr1→example→exon→1200→2100→.→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
warning[GTF012]: feature type `transcript` is not one of the nine GTF 2.2 types
 --> example.gtf:1:14
  |
1 | chr1→example→transcript→1200→2100→.→+→.→gene_id "g1"; transcript_id "g1.t1";
  |              ^^^^^^^^^^
  = help: Ensembl and GENCODE files contain these lines and current tools accept them; a parser that follows GTF 2.2 ignores the line
  = spec: GTF 2.2, GTF Field Definitions: <feature>
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF012`, or check only this rule with `--select GTF012`.
