# VCF011: Flag must have Number=0 (and only Flag may)

| | |
|---|---|
| Name | `meta-flag-number` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.2 |

A `Flag` carries no value, so its `Number` must be `0`. Conversely `Number=0` only makes sense for a Flag.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DB,Number=1,Type=Flag,Description="dbSNP membership">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DB
```

biolint reports:

```text
error[VCF011]: a Flag takes no value, so its Number must be 0, not 1
 --> example.vcf:2:22
  |
2 | ##INFO=<ID=DB,Number=1,Type=Flag,Description="dbSNP membership">
  |                      ^
  = help: write `Number=0`
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF011`, or check only this rule with `--select VCF011`.
