# GTF104: Last attribute does not end with a semicolon

| | |
|---|---|
| Name | `final-semicolon-missing` |
| Format | GTF |
| Level | `warning` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

The last attribute of a line needs its semicolon too. Parsers generally accept the line without it, and HTSeq itself writes such lines (the annotation DEXSeq prepares, for example), which is why this is a warning by default.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1"
```

biolint reports:

```text
warning[GTF104]: the last attribute, `transcript_id`, does not end with a semicolon
 --> example.gtf:1:69
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1"
  |                                                                     ^
  = help: add `;` at the end of the line
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF104`, or check only this rule with `--select GTF104`.
