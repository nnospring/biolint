# GFF109: Strand is not +, -, . or ?

| | |
|---|---|
| Name | `strand-invalid` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Column 7: "strand" |

The strand is `+`, `-`, `.` for a feature without a strand, or `?` when the strand matters but is unknown. Numeric strands (`1`, `-1`) come from Ensembl tables and BioMart exports. GenomeTools rejects any other value, and a tool that does not reject it cannot know which strand to extract.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→-1→.→ID=gene1
```

biolint reports:

```text
error[GFF109]: strand `-1` is not one of `+`, `-`, `.`, `?`
 --> example.gff3:2:31
  |
2 | chr1→example→gene→2100→7400→.→-1→.→ID=gene1
  |                               ^^
  = help: write `-` for the reverse strand (numeric strands are an Ensembl/BioMart convention)
  = spec: GFF3 1.26, Column 7: "strand"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF109`, or check only this rule with `--select GFF109`.
