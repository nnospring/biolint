# VCF014: ID contains characters that are not allowed

| | |
|---|---|
| Name | `meta-id-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4, §1.6.1 |

INFO and FORMAT keys must match `[A-Za-z_][0-9A-Za-z_.]*` (4.3 and later). FILTER IDs may not contain whitespace or semicolons and may not be `0`. Contig names may not contain whitespace, commas or angle brackets. IDs with such characters cannot be told apart from the delimiters around them.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=read-depth,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF014]: INFO ID `read-depth` must match `[A-Za-z_][0-9A-Za-z_.]*`
 --> example.vcf:2:12
  |
2 | ##INFO=<ID=read-depth,Number=1,Type=Integer,Description="Total depth">
  |            ^^^^^^^^^^
  = help: rename it, e.g. `read_depth`, in the header and in every record
  = spec: VCF 4.3 §1.4, §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF014`, or check only this rule with `--select VCF014`.
