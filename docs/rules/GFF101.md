# GFF101: Feature line does not have nine tab-separated columns

| | |
|---|---|
| Name | `column-count` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Description of the Format |

Every feature line has exactly nine columns separated by single tab characters: seqid, source, type, start, end, score, strand, phase, attributes. Spaces are legal inside values, so parsers split on tabs only. The usual cause is an editor or a copy-paste that turned tabs into spaces (HTSeq and GenomeTools both stop at such a line); a missing ninth column (write `.` when there are no attributes) and a line break inside a value are the others.

## Example

Separated by spaces:

```text
##gff-version 3
chr1 example gene 1000 9000 . + . ID=gene1
```

biolint reports:

```text
error[GFF101]: line has 1 column, expected 9
 --> example.gff3:2:43
  |
2 | chr1 example gene 1000 9000 . + . ID=gene1
  |                                           ^
  = help: the fields are separated by spaces; GFF3 columns must be separated by single tab characters (a text editor or copy-paste often converts tabs to spaces)
  = spec: GFF3 1.26, Description of the Format
```

No attributes column:

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.
```

biolint reports:

```text
error[GFF101]: line has 8 columns, expected 9
 --> example.gff3:2:34
  |
2 | chr1→example→gene→2100→7400→.→+→.
  |                                  ^
  = help: the attributes column is missing; write `.` in column 9 if a feature has no attributes
  = spec: GFF3 1.26, Description of the Format
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region chr1 1 50000
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Name=abcA
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
chr1→example→exon→2100→2600→.→+→.→Parent=tx1
chr1→example→exon→4000→7400→.→+→.→Parent=tx1
chr1→example→CDS→2300→2600→.→+→0→ID=cds1;Parent=tx1
chr1→example→CDS→4000→4701→.→+→2→ID=cds1;Parent=tx1
```

## Configuration

Silence it with `--ignore GFF101`, or check only this rule with `--select GFF101`.
