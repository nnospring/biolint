# GFF213: Gap is not a list of operations such as "M210 D12 M238"

| | |
|---|---|
| Name | `gap-invalid` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, The Gap Attribute |

A `Gap` describes an alignment as operations separated by spaces, each a letter (`M` match, `I` insertion, `D` deletion, `F` and `R` frameshifts) followed by a length: `M210 D12 M238`. This is the reverse of SAM CIGAR strings, where the number comes first and nothing separates the operations.

## Example

```text
##gff-version 3
scaffold7→aligner→cDNA_match→2001→2460→.→+→.→ID=aln1;Target=mrna0042 1 448;Gap=210M12D238M
```

biolint reports:

```text
warning[GFF213]: Gap `210M12D238M` is not a list of operations such as `M210 D12 M238`
 --> example.gff3:2:80
  |
2 | scaffold7→aligner→cDNA_match→2001→2460→.→+→.→ID=aln1;Target=mrna0042 1 448;Gap=210M12D238M
  |                                                                                ^^^^^^^^^^^
  = help: this is written like a SAM CIGAR string; in GFF3 the letter comes first and operations are separated by spaces: `M210 D12 M238`
  = spec: GFF3 1.26, The Gap Attribute
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
scaffold7→aligner→cDNA_match→2001→2460→97.5→+→.→ID=aln1;Target=mrna0042 1 448;Gap=M210 D12 M238
scaffold7→aligner→cDNA_match→6100→6385→3.1e-30→-→.→ID=aln2;Target=mrna0077 15 300 +
scaffold7→aligner→cDNA_match→7020→7339→2.4e-35→-→.→ID=aln2;Target=mrna0077 301 620 +
```

## Configuration

Silence it with `--ignore GFF213`, or check only this rule with `--select GFF213`.
