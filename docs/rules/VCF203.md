# VCF203: Invalid CHROM

| | |
|---|---|
| Name | `chrom-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

CHROM is a contig name without whitespace (and, in strict mode, restricted to the characters SAM allows for reference names), or an angle-bracketed assembly ID.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
chr 1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF203]: CHROM `chr 1` contains whitespace
 --> example.vcf:3:1
  |
3 | chr 1→100→.→A→T→.→.→.
  | ^^^^^
  = help: contig names cannot contain spaces; check that the columns are separated by tabs
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF203`, or check only this rule with `--select VCF203`.
