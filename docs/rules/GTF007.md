# GTF007: Strand is not +, - or a dot

| | |
|---|---|
| Name | `strand-invalid` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions (the strand column is inherited from GFF) |

The strand is `+` or `-`; `.` is used for features without a strand, such as the single-exon transcripts StringTie cannot orient. Numeric strands (`1`, `-1`) come from Ensembl tables and BioMart exports. Some tools are stricter than the format: RSEM stops at any line whose strand is not `+` or `-`.

## Example

```text
chr1→example→exon→1200→1350→.→1→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF007]: strand `1` is not one of `+`, `-`, `.`
 --> example.gtf:1:31
  |
1 | chr1→example→exon→1200→1350→.→1→.→gene_id "g1"; transcript_id "g1.t1";
  |                               ^
  = help: write `+` for the forward strand (numeric strands are an Ensembl/BioMart convention)
  = spec: GTF 2.2, GTF Field Definitions (the strand column is inherited from GFF)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF007`, or check only this rule with `--select GTF007`.
