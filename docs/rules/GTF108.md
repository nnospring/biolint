# GTF108: Feature has no gene_id

| | |
|---|---|
| Name | `gene-id-missing` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

Every feature line carries a `gene_id` attribute; it is what makes a GTF file different from a plain GFF2 file. Read counters group exons by it: featureCounts stops with "failed to find the gene identifier attribute" and HTSeq with "Feature ... does not contain a 'gene_id' attribute". An empty value (`gene_id "";`) is allowed for features that belong to no gene.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→transcript_id "g1.t1"; gene_name "ABC1";
```

biolint reports:

```text
error[GTF108]: the line has no `gene_id` attribute
 --> example.gtf:1:35
  |
1 | chr1→example→exon→1200→1350→.→+→.→transcript_id "g1.t1"; gene_name "ABC1";
  |                                   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: add `gene_id "...";` as the first attribute; tools that count reads per gene need it on every line
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF108`, or check only this rule with `--select GTF108`.
