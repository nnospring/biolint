# FQ011: Whitespace in a sequence or quality line

| | |
|---|---|
| Name | `whitespace-in-record` |
| Format | FASTQ |
| Level | `error` |
| Source | Cock et al. 2010 (NAR 38:1767), "FASTQ definition" ("White space such as tabs or spaces is not permitted") |

Spaces and tabs are not allowed in the sequence, and are not quality characters (the quality range starts at `!`, one above the space). They appear when a table was converted to FASTQ incompletely or a line picked up trailing spaces in an editor; parsers then count them as bases or scores, or stop.

## Example

A space inside the sequence:

```text
@read1
ACGT ACGT
+
IIIIIIIII
```

biolint reports:

```text
error[FQ011]: 1 whitespace character in the sequence of read `read1`
 --> example.fastq:2:5
  |
2 | ACGT ACGT
  |     ^
  = help: whitespace is not allowed in a sequence; the file may be a table that was converted incompletely
  = spec: Cock et al. 2010 (NAR 38:1767), "FASTQ definition" ("White space such as tabs or spaces is not permitted")
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FQ011`, or check only this rule with `--select FQ011`.
