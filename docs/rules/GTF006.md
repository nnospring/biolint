# GTF006: Score is not a number

| | |
|---|---|
| Name | `score-invalid` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: <score> |

The score is an integer or floating point number, or `.` when there is none. Readers convert the column to a number: HTSeq, for one, stops with a conversion error when it holds text such as `NA` or a decimal comma.

## Example

```text
chr1→example→exon→1200→1350→NA→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF006]: score `NA` is not a number
 --> example.gtf:1:29
  |
1 | chr1→example→exon→1200→1350→NA→+→.→gene_id "g1"; transcript_id "g1.t1";
  |                             ^^
  = help: write `.` when there is no score
  = spec: GTF 2.2, GTF Field Definitions: <score>
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF006`, or check only this rule with `--select GTF006`.
