# SAM112: Alignment lies beyond the end of its reference

| | |
|---|---|
| Name | `pos-beyond-reference` |
| Format | SAM |
| Level | `warning` |
| Source | SAM v1 §2 |

POS, or the last base the CIGAR covers, is larger than the `LN` of the reference in the header. The specification recommends that such a read be flagged unmapped (unless the reference is circular, `TP:circular`). It nearly always means the header describes a different reference build than the one the reads were aligned to.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→2000→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM112]: POS 2000 is beyond the end of `chr1` (LN:1000)
 --> example.sam:3:11
  |
3 | r1→0→chr1→2000→30→5M→*→0→0→ACGTA→IIIII
  |           ^^^^
  = help: the header probably describes a different reference build than the one used for alignment
  = note: @SQ line 2
  = spec: SAM v1 §2
```

The alignment starts inside the reference and runs past its end:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→998→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM112]: the alignment ends at 1002, beyond the end of `chr1` (LN:1000)
 --> example.sam:3:11
  |
3 | r1→0→chr1→998→30→5M→*→0→0→ACGTA→IIIII
  |           ^^^^^^^^^
  = help: check that the header matches the reference used for alignment; if the reference is circular, add `TP:circular` to its @SQ line
  = note: @SQ line 2
  = spec: SAM v1 §2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM112`, or check only this rule with `--select SAM112`.
