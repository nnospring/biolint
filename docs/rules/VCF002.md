# VCF002: Unrecognised ##fileformat value

| | |
|---|---|
| Name | `fileformat-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.1 |

The value must be `VCFv` followed by the version, exactly: `VCFv4.1`, `VCFv4.2`, `VCFv4.3`, `VCFv4.4` or `VCFv4.5`. Variants such as `VCF4.2`, `vcfv4.2` or `VCFv4.2 ` (trailing space) are not recognised by parsers.

## Example

```text
##fileformat=VCF4.2
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF002]: `VCF4.2` is not a VCF version this tool knows
 --> example.vcf:1:14
  |
1 | ##fileformat=VCF4.2
  |              ^^^^^^
  = help: did you mean `##fileformat=VCFv4.2`?
  = note: checking the rest of the file as VCF 4.2
  = spec: VCF 4.3 §1.4.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF002`, or check only this rule with `--select VCF002`.
