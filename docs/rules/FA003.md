# FA003: Whitespace between > and the identifier

| | |
|---|---|
| Name | `header-leading-whitespace` |
| Format | FASTA |
| Level | `warning` |
| Source | faidx(5) |

Tools disagree about `> name`. `samtools faidx` skips the space and calls the sequence `name`; parsers that take "everything up to the first space" get an empty identifier, so the same file yields different sequence names in different programs. Remove the space.

## Example

```text
> seq1 sample A
ACGTACGT
```

biolint reports:

```text
warning[FA003]: whitespace between `>` and the identifier `seq1`
 --> example.fasta:1:2
  |
1 | > seq1 sample A
  |  ^
  = help: write `>seq1`: samtools skips the space, but other parsers read an empty identifier
  = fix: Remove the whitespace after > (--fix)
  = spec: faidx(5)
```

In these listings `→` stands for a tab.

## Accepted

```text
>seq1 sample A
ACGTACGT
```

## Configuration

Silence it with `--ignore FA003`, or check only this rule with `--select FA003`.
