# BED015: Value is wrapped in quotation marks

| | |
|---|---|
| Name | `quoted-field` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.5 |

BED has no quoting: a quotation mark is part of the value, so `"chr1"` is a chromosome that exists in no genome and `"1000"` is not a number. Quotes are added by R (`write.table` quotes text columns unless `quote = FALSE`) and by CSV exports from spreadsheets.

## Example

```text
"chr1"→1000→5000
```

biolint reports:

```text
error[BED015]: chrom `"chr1"` starts with a quotation mark
 --> example.bed:1:1
  |
1 | "chr1"→1000→5000
  | ^^^^^^
  = help: BED has no quoting, so the quotes become part of the name: write `chr1`. In R use `write.table(..., quote = FALSE)`; from a spreadsheet, export as tab-separated text
  = spec: BED v1.0 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED015`, or check only this rule with `--select BED015`.
