# SAM115: Clipping operation in the middle of a CIGAR

| | |
|---|---|
| Name | `cigar-clipping` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.4 |

Clipping describes the ends of a read: `H` (hard clip) may only be the first or last operation, and `S` (soft clip) may only have `H` between it and the end of the CIGAR. Inside an alignment, use `I` for bases missing from the reference or `N` for a skipped region. samtools does not check this.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→2M1S2M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM115]: soft clip `1S` is inside CIGAR `2M1S2M`, not at an end
 --> example.sam:3:19
  |
3 | r1→0→chr1→10→30→2M1S2M→*→0→0→ACGTA→IIIII
  |                   ^^
  = help: `S` may only be separated from the ends of the CIGAR by `H`; use `I` for read bases that are not aligned in the middle of an alignment
  = spec: SAM v1 §1.4
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→1S2H4M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM115]: hard clip `2H` is inside CIGAR `1S2H4M`, not at an end
 --> example.sam:3:19
  |
3 | r1→0→chr1→10→30→1S2H4M→*→0→0→ACGTA→IIIII
  |                   ^^
  = help: `H` may only be the first or the last operation; use `D` or `N` for reference bases the read skips, and split a chimeric read into supplementary records
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→3H1S3M1S2H→*→0→0→ACGTA→IIIII
```

## Configuration

Silence it with `--ignore SAM115`, or check only this rule with `--select SAM115`.
