# FA011: Digits inside a sequence

| | |
|---|---|
| Name | `sequence-digits` |
| Format | FASTA |
| Level | `error` |
| Source | NCBI BLAST help, FASTA ("any numerical digits in the query sequence should either be removed or replaced") |

Digits are not residue codes. They are almost always the position numbers of a GenBank, EMBL or web-page listing that was pasted as is. Indexers count them as bases, which shifts every coordinate after them. Strip the numbers and spaces: `sed -i '/^>/! s/[0-9 \t]//g' file.fa`.

## Example

Position numbers and spaces from a GenBank flat file:

```text
>U49845.1 pasted from the GenBank ORIGIN block
        1 gatcctccat atacaacggt atctccacct caggtttaga tctcaacaac ggaaccattg
       61 ccgacatgag acagttaggt atcgtcgaga gttacaagct aaaacgagca gtagtcagct
```

biolint reports:

```text
error[FA011]: sequence line contains the number `1` and 14 spaces: it was pasted from a numbered listing
 --> example.fasta:2:9
  |
2 |         1 gatcctccat atacaacggt atctccacct caggtttaga tctcaacaac ggaaccattg
  |         ^
  = help: strip the position numbers and spaces from the sequence lines: `sed -i '/^>/! s/[0-9 \t]//g' file.fa`
  = spec: NCBI BLAST help, FASTA ("any numerical digits in the query sequence should either be removed or replaced")

error[FA011]: sequence line contains the number `61` and 13 spaces: it was pasted from a numbered listing
 --> example.fasta:3:8
  |
3 |        61 ccgacatgag acagttaggt atcgtcgaga gttacaagct aaaacgagca gtagtcagct
  |        ^^
  = help: strip the position numbers and spaces from the sequence lines: `sed -i '/^>/! s/[0-9 \t]//g' file.fa`
  = spec: NCBI BLAST help, FASTA ("any numerical digits in the query sequence should either be removed or replaced")
```

```text
>seq1
ACGTACGT10ACGT
```

biolint reports:

```text
error[FA011]: digits `10` in the sequence
 --> example.fasta:2:9
  |
2 | ACGTACGT10ACGT
  |         ^^
  = help: remove the digits; if they stand for unknown residues write `N` (nucleotide) or `X` (protein)
  = spec: NCBI BLAST help, FASTA ("any numerical digits in the query sequence should either be removed or replaced")
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA011`, or check only this rule with `--select FA011`.
