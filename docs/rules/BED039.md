# BED039: thickStart or thickEnd is -1

| | |
|---|---|
| Name | `thick-minus-one` |
| Format | BED |
| Level | `warning` by default, `error` with `--strict` |
| Source | BED v1.0 §1.8 |

Some annotation files (the reference annotations of Rp-Bp are one example) carry `-1` in thickStart and thickEnd for transcripts without a coding region. Interval tools that ignore these columns read the file, but the specification defines both as non-negative positions, so a tool that validates them may refuse it. The portable way to say "no thick part" is chromStart in both columns.

## Example

```text
chr20→87249→97094→ENST00000382410→0→+→87709→96414
chr20→87671→97094→ENST00000608838→0→+→-1→-1
```

biolint reports:

```text
warning[BED039]: thickStart is `-1`, a convention some tools use for "no coding region"
 --> example.bed:2:39
  |
2 | chr20→87671→97094→ENST00000608838→0→+→-1→-1
  |                                       ^^
  = help: write `87671` (chromStart) in both thickStart and thickEnd for a feature without a thick part
  = note: 8 fields per line, all read as standard fields (BED8, inferred from line 1); if column 7 is a custom field instead, declare it with `--option bed.type=bed6+2`
  = spec: BED v1.0 §1.8

warning[BED039]: thickEnd is `-1`, a convention some tools use for "no coding region"
 --> example.bed:2:42
  |
2 | chr20→87671→97094→ENST00000608838→0→+→-1→-1
  |                                          ^^
  = help: write `87671` (chromStart) in both thickStart and thickEnd for a feature without a thick part
  = spec: BED v1.0 §1.8
```

In these listings `→` stands for a tab.

## Accepted

```text
chr20→87249→97094→ENST00000382410→0→+→87709→96414
chr20→87671→97094→ENST00000608838→0→+→87671→87671
```

## Configuration

Silence it with `--ignore BED039`, or check only this rule with `--select BED039`.
