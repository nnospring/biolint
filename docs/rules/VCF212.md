# VCF212: Invalid ALT allele

| | |
|---|---|
| Name | `alt-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

Each comma-separated ALT allele is a string of `A`/`C`/`G`/`T`/`N`, `*` (spanning deletion, from 4.2), `.` (no variant, alone), a symbolic allele `<ID>`, or a breakend such as `G]17:198982]`. `-`, empty entries and lower-level notation such as `A>T` are invalid.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T,→.→.→.
```

biolint reports:

```text
error[VCF212]: empty ALT allele (stray comma)
 --> example.vcf:3:12
  |
3 | 1→100→.→A→T,→.→.→.
  |            ^
  = help: remove the extra comma, or write `.` if there is no alternate allele
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF212`, or check only this rule with `--select VCF212`.
