# BED002: File contains browser or track lines

| | |
|---|---|
| Name | `track-line` |
| Format | BED |
| Level | `info` by default, `error` with `--strict` |
| Source | BED v1.0 §5 |

`browser` and `track` lines configure the UCSC Genome Browser. Genome browsers accept them at the top of a file, but the specification calls such a file a *track file*, not a BED file, and a parser that expects plain BED reads these lines as data. Remove them, or keep the annotated copy for the browser only.

## Example

```text
track name="peaks" description="ChIP-seq peaks" useScore=1
chr1→1000→5000→peak1→960
```

biolint reports:

```text
info[BED002]: `track` line: this is a UCSC track file, not plain BED
 --> example.bed:1:1
  |
1 | track name="peaks" description="ChIP-seq peaks" useScore=1
  | ^^^^^
  = help: delete the line for use outside a genome browser (`grep -v -E '^(track|browser)' file.bed`)
  = spec: BED v1.0 §5
```

In these listings `→` stands for a tab.

## Accepted

```text
# peaks called on 2024-03-01
chr7→127471196→127472363→Pos1→0→+
chr7→127472363→127473530→Pos2→0→+
chr7→127475864→127477031→Neg1→0→-
```

## Configuration

Silence it with `--ignore BED002`, or check only this rule with `--select BED002`.
