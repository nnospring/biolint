# GFF112: Percent sign is not part of an escape

| | |
|---|---|
| Name | `percent-escape-invalid` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Description of the Format |

GFF3 uses URL-style escapes: `%` followed by two hexadecimal digits stands for one character (`%3B` is a semicolon). A literal percent sign must therefore be written `%25`. What a parser makes of text such as `95% identity` is not defined: the `%` may be kept, dropped, or decoded together with the two characters after it.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Note=95% identity to abcA
```

biolint reports:

```text
warning[GFF112]: `%` is not followed by two hexadecimal digits
 --> example.gff3:2:51
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1;Note=95% identity to abcA
  |                                                   ^
  = help: write a literal percent sign as `%25`
  = spec: GFF3 1.26, Description of the Format
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Note=95%25 identity to abcA%3B curated
```

## Configuration

Silence it with `--ignore GFF112`, or check only this rule with `--select GFF112`.
