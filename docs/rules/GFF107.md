# GFF107: Start is greater than end

| | |
|---|---|
| Name | `start-after-end` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Columns 4 & 5: "start" and "end" |

Start is always less than or equal to end, also for features on the minus strand: the strand column gives the direction, not the order of the coordinates. A feature that crosses the origin of a circular sequence is written with end = its true end + the length of the sequence, so that start stays below end.

## Example

```text
##gff-version 3
chr1→example→gene→7400→2100→.→-→.→ID=gene1
```

biolint reports:

```text
error[GFF107]: start 7400 is greater than end 2100
 --> example.gff3:2:19
  |
2 | chr1→example→gene→7400→2100→.→-→.→ID=gene1
  |                   ^^^^^^^^^
  = help: write the smaller coordinate first (start 2100, end 7400): the `-` in column 7 already says the feature is on the reverse strand
  = spec: GFF3 1.26, Columns 4 & 5: "start" and "end"
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region pX01 1 4821
pX01→example→region→1→4821→.→+→.→ID=pX01;Is_circular=true
pX01→example→CDS→4500→5120→.→+→0→ID=cds1;Name=repA
```

## Configuration

Silence it with `--ignore GFF107`, or check only this rule with `--select GFF107`.
