# GFF306: Feature refers across a ### line

| | |
|---|---|
| Name | `closed-by-terminator` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Other Syntax: ### |

A `###` line declares that all features above it are complete: nothing below will name them as `Parent` or continue them with the same ID. Programs that read a file gene by gene release what they have at each `###`, so a child placed after it never finds its parent. This happens when `###` lines are kept while the features are re-sorted, or inserted at fixed intervals instead of between genes.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
###
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
```

biolint reports:

```text
warning[GFF306]: Parent `gene1` was closed by the `###` on line 3
 --> example.gff3:4:49
  |
4 | chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
  |                                                 ^^^^^
  = help: a `###` line promises that no later feature refers to those above it: move this feature above it, or remove the `###` lines
  = note: the parent is defined on line 2
  = spec: GFF3 1.26, Other Syntax: ###
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
chr1→example→exon→2100→2600→.→+→.→Parent=tx1
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
chr1→example→gene→2100→7400→.→+→.→ID=gene1
###
chr1→example→gene→12000→15000→.→-→.→ID=gene2
```

## Configuration

Silence it with `--ignore GFF306`, or check only this rule with `--select GFF306`.
