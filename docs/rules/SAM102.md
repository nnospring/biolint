# SAM102: Mandatory field is empty

| | |
|---|---|
| Name | `field-empty` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

None of the eleven mandatory fields may be empty. Missing information is written as `*` (QNAME, RNAME, CIGAR, RNEXT, SEQ, QUAL) or `0` (FLAG, POS, MAPQ, PNEXT, TLEN). Two tabs in a row usually come from a script that printed an undefined value.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM102]: RNEXT (column 7) is empty
 --> example.sam:3:19
  |
3 | r1→0→chr1→10→30→5M→→0→0→ACGTA→IIIII
  |                   ^^
  = help: write `*` when there is no value; two tabs in a row usually mean a script printed an empty variable
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM102`, or check only this rule with `--select SAM102`.
