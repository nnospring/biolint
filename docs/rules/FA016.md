# FA016: File switches from nucleotide to protein sequences

| | |
|---|---|
| Name | `alphabet-switch` |
| Format | FASTA |
| Level | `warning` |
| Source | NCBI BLAST help, FASTA |

The file started with nucleotide sequences, and from this record on the lines look like protein (many letters that are not nucleotide codes). Databases and indexes are built for one kind of sequence (`makeblastdb -dbtype nucl` or `prot`), so a mixed file is mis-handled. If the mix is intended, split the file; biolint stops checking letters against the nucleotide codes from here.

Silence it with `--ignore FA016`, or check only this rule with `--select FA016`.
