# SAM211: Reads carry RG tags but the header has no @RG lines

| | |
|---|---|
| Name | `rg-header-missing` |
| Format | SAM |
| Level | `warning` |
| Source | SAM v1 §2 |

The specification recommends one `@RG` line for every read group named by an `RG:Z:` tag. Without it the read group has no sample, library or platform. Reported once per file.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:lane1
```

biolint reports:

```text
warning[SAM211]: reads carry `RG:Z:lane1`, but the header has no @RG lines
 --> example.sam:3:43
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:lane1
  |                                           ^^^^^
  = help: add `@RG<tab>ID:lane1<tab>SM:<sample>` to the header (`samtools addreplacerg` can do this)
  = spec: SAM v1 §2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM211`, or check only this rule with `--select SAM211`.
