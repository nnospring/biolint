# VCF210: Invalid REF allele

| | |
|---|---|
| Name | `ref-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

REF is one or more of `A`, `C`, `G`, `T`, `N` (any case). It cannot be `.`, `-` or empty: an insertion or deletion includes the preceding reference base. A `-` allele means the file came from a MAF/annovar-style table and needs left-padding against the reference.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→-→T→.→.→.
```

biolint reports:

```text
error[VCF210]: REF `-` is not a sequence of bases
 --> example.vcf:3:9
  |
3 | 1→100→.→-→T→.→.→.
  |         ^
  = help: REF cannot be empty or missing: for an insertion, give the reference base before it and start ALT with the same base (e.g. REF=`A`, ALT=`ATG`)
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF210`, or check only this rule with `--select VCF210`.
