# SAM204: Unknown optional field type

| | |
|---|---|
| Name | `aux-type-unknown` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.5 |

The type is one case-sensitive letter: `A` (character), `i` (integer), `f` (number), `Z` (string), `H` (hex bytes) or `B` (numeric array). The letters `c C s S` are sizes used inside BAM; in SAM text every integer is `i`. samtools rejects most other letters and misreads some (`XC:c:5` is stored as the character "5"). The two letters it reads correctly, `I` and `d`, are reported by a separate rule.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→XS:z:text
```

biolint reports:

```text
error[SAM204]: `z` is not an optional field type
 --> example.sam:3:41
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→XS:z:text
  |                                         ^
  = help: types are case-sensitive: write `XS:Z:...`
  = spec: SAM v1 §1.5
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:S:2
```

biolint reports:

```text
error[SAM204]: `S` is not an optional field type
 --> example.sam:3:41
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:S:2
  |                                         ^
  = help: `S` is a BAM storage size; in SAM text every integer has type `i`: write `NM:i:2`
  = spec: SAM v1 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM204`, or check only this rule with `--select SAM204`.
