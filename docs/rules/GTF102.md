# GTF102: Attribute is not a key followed by a value

| | |
|---|---|
| Name | `attribute-malformed` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

Each attribute is a key, a space and a value, ended by a semicolon: `gene_id "g1";`. A key with nothing after it, or a value with no key in front, cannot be read, and parsers stop at the line.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id;
```

biolint reports:

```text
error[GTF102]: attribute `transcript_id` has no value
 --> example.gtf:1:49
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id;
  |                                                 ^^^^^^^^^^^^^
  = help: write `transcript_id "...";`, or `transcript_id "";` if it is deliberately empty
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF102`, or check only this rule with `--select GTF102`.
