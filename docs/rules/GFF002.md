# GFF002: ##gff-version is not version 3

| | |
|---|---|
| Name | `version-invalid` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Other Syntax: ##gff-version |

The version is written `3`, optionally followed by a revision as in `3.1.26`, and separated from `##gff-version` by a space. A file that declares version 2 is GFF2 or GTF: its ninth column uses `key "value";` pairs, and it has to be converted (for example with `gffread` or AGAT) before a GFF3 tool can read it.

## Example

The file says it is GFF2:

```text
##gff-version 2
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
error[GFF002]: the file declares GFF version 2, not GFF3
 --> example.gff3:1:15
  |
1 | ##gff-version 2
  |               ^
  = help: GFF2 and GTF write column 9 as `key "value";` pairs: check the file with `--type gtf`, or convert it to GFF3 with `gffread` or AGAT
  = note: checking the file as GFF3
  = spec: GFF3 1.26, Other Syntax: ##gff-version
```

No space before the version:

```text
##gff-version3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
error[GFF002]: `##gff-version3` is not a version directive: a space must separate `##gff-version` from the number
 --> example.gff3:1:1
  |
1 | ##gff-version3
  | ^^^^^^^^^^^^^^
  = help: write `##gff-version 3`
  = spec: GFF3 1.26, Other Syntax: ##gff-version
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF002`, or check only this rule with `--select GFF002`.
