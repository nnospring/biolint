# VCF218: QUAL is negative

| | |
|---|---|
| Name | `qual-negative` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.6.1 |

QUAL is −10·log10 of an error probability, so it cannot be negative. A negative value usually means another column slipped into this position, or a caller wrote a log-likelihood.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→-10→.→.
```

biolint reports:

```text
warning[VCF218]: QUAL -10 is negative
 --> example.vcf:3:13
  |
3 | 1→100→.→A→T→-10→.→.
  |             ^^^
  = help: QUAL is a Phred-scaled probability and cannot be below 0; write `.` if it is unknown
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF218`, or check only this rule with `--select VCF218`.
