# GFF102: Line ends with an extra tab

| | |
|---|---|
| Name | `trailing-tab` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Description of the Format |

A tab after the attributes column creates an empty tenth column. A parser that takes the first nine fields ignores it; one that counts columns rejects the line. Spreadsheet exports and scripts that append `"\t"` to every field produce it.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1→
```

biolint reports:

```text
warning[GFF102]: the line ends with a tab after the attributes column
 --> example.gff3:2:43
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1→
  |                                           ^
  = help: remove the trailing tab
  = spec: GFF3 1.26, Description of the Format
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF102`, or check only this rule with `--select GFF102`.
