# GTF109: Transcript feature has no transcript_id

| | |
|---|---|
| Name | `transcript-id-missing` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

Exons, coding segments, codons and UTRs belong to a transcript, named by `transcript_id`. Without it, tools that build transcript models cannot tell which exons go together: RSEM stops with "Cannot find transcript_id!". Files written for gene-level counting only sometimes omit it; add the transcript, or use the gene identifier when each gene has one transcript.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; gene_name "ABC1";
```

biolint reports:

```text
error[GTF109]: the exon line has no `transcript_id` attribute
 --> example.gtf:1:35
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; gene_name "ABC1";
  |                                   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: add `transcript_id "...";` after `gene_id`; if the annotation has one transcript per gene, the gene identifier can be reused
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF109`, or check only this rule with `--select GTF109`.
