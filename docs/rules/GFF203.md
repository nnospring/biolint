# GFF203: Attribute has no value

| | |
|---|---|
| Name | `attribute-value-empty` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Column 9: "attributes" |

An attribute is `tag=value`; a tag followed by `=` and nothing else carries no information, and GenomeTools rejects it. Scripts that print every field of a table produce `Note=;` for missing values: leave the attribute out instead. An empty `ID=` or `Parent=` also means the feature is not linked to its gene.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Note=
```

biolint reports:

```text
warning[GFF203]: attribute `Note` has no value
 --> example.gff3:2:44
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1;Note=
  |                                            ^^^^^
  = help: leave the attribute out when there is nothing to say
  = spec: GFF3 1.26, Column 9: "attributes"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF203`, or check only this rule with `--select GFF203`.
