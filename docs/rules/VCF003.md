# VCF003: ##fileformat appears more than once

| | |
|---|---|
| Name | `fileformat-repeated` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.1 |

A file has exactly one `##fileformat` line, and it is the first line. A second one almost always means two VCF files were concatenated with `cat`; use `bcftools concat` instead.

## Example

```text
##fileformat=VCFv4.3
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF003]: `##fileformat` appears again; it belongs on the first line only
 --> example.vcf:2:1
  |
2 | ##fileformat=VCFv4.3
  | ^^^^^^^^^^^^^^^^^^^^
  = help: if two VCF files were joined with `cat`, use `bcftools concat` or `bcftools merge` instead
  = spec: VCF 4.3 §1.4.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF003`, or check only this rule with `--select VCF003`.
