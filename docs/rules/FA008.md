# FA008: Sequence identifier is used more than once

| | |
|---|---|
| Name | `duplicate-id` |
| Format | FASTA |
| Level | `warning` by default, `error` with `--strict` |
| Source | faidx(5) |

Two records have the same identifier (the header text up to the first whitespace; the description after it does not count). `samtools faidx` warns "Ignoring duplicate sequence" and indexes only the first, so the second can never be retrieved, and tools that need unique names (such as `makeblastdb -parse_seqids`) stop. Duplicates come from concatenating files, or from identifiers that differ only after the first space.

## Example

```text
>seq1 first copy
ACGTACGT
>seq1 second copy
TTTTACGT
```

biolint reports:

```text
warning[FA008]: identifier `seq1` was already used on line 1
 --> example.fasta:3:2
  |
3 | >seq1 second copy
  |  ^^^^
  = help: make the identifiers unique (the description after the first space does not count); `seqkit rename` appends a suffix to repeats
  = note: first used on line 1
  = spec: faidx(5)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA008`, or check only this rule with `--select FA008`.
