# SAM007: Header line lacks a required tag

| | |
|---|---|
| Name | `header-required-missing` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.3 |

Every `@SQ` line needs `SN` (name) and `LN` (length); every `@RG` and `@PG` line needs `ID`. samtools refuses a header without them. Tags are case-sensitive, so `sn:` or `Id:` do not count.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1
r1→4→*→0→0→*→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM007]: `@SQ` line has no `LN`
 --> example.sam:2:1
  |
2 | @SQ→SN:chr1
  | ^^^
  = help: add `LN:<length in bases>`; `samtools dict ref.fa` writes correct @SQ lines
  = spec: SAM v1 §1.3
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@RG→SM:sample1
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM007]: `@RG` line has no `ID`
 --> example.sam:3:1
  |
3 | @RG→SM:sample1
  | ^^^
  = help: add `ID:<value>`
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM007`, or check only this rule with `--select SAM007`.
