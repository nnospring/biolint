# TXT009: File does not end with a newline

| | |
|---|---|
| Name | `no-final-newline` |
| Format | Any format |
| Level | `warning` |
| Fixable | yes, with `biolint --fix` |

The last line has no terminating newline. Concatenating such files glues the last record of one onto the first record of the next, and some parsers drop an unterminated last line. It can also mean the file was truncated.

## Example

```text
>seq1
ACGT
```

biolint reports:

```text
warning[TXT009]: the last line is not terminated by a newline
 --> example.fasta:2
  = help: append a newline; if the file should be longer, it may be truncated
  = fix: Add a final newline (--fix)
```

In these listings `→` stands for a tab.

## Accepted

```text
>seq1
ACGT
```

## Configuration

Silence it with `--ignore TXT009`, or check only this rule with `--select TXT009`.
