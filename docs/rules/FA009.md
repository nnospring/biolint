# FA009: Comment line in a FASTA file

| | |
|---|---|
| Name | `comment-line` |
| Format | FASTA |
| Level | `error` |
| Source | NCBI BLAST help, FASTA; faidx(5) |

A line starts with `;` or `#`. The original FASTA programs accepted `;` comment lines and a few libraries tolerate `#`, but current tools do not: before the first header `samtools faidx` fails, and inside a record the comment text is read as sequence. Delete the comment lines or move the text into the description after `>id`.

## Example

```text
>seq1
ACGTACGT
# trimmed with my_script v2
>seq2
ACGTACGT
```

biolint reports:

```text
error[FA009]: comment line starting with `#`
 --> example.fasta:3:1
  |
3 | # trimmed with my_script v2
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: delete the line, or move its text into the description after `>id`; tools read it as sequence or stop
  = spec: NCBI BLAST help, FASTA; faidx(5)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA009`, or check only this rule with `--select FA009`.
