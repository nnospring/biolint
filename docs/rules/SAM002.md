# SAM002: Unknown header record type

| | |
|---|---|
| Name | `header-type-unknown` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.3 |

Header lines start with `@` and one of five two-letter codes in upper case: `@HD`, `@SQ`, `@RG`, `@PG` or `@CO`. New fields may be added inside these lines, but new line types may not, and samtools stops with "Invalid header line". A FASTQ-style read name that begins with `@` on the first alignment line is read as a header line and fails the same way.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@XY→ID:custom
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM002]: `@XY` is not a header record type
 --> example.sam:3:1
  |
3 | @XY→ID:custom
  | ^^^
  = help: new record types cannot be added; put free text in a `@CO` line, or add your own lower-case tag to an existing line
  = spec: SAM v1 §1.3
```

Record type codes are upper case:

```text
@HD→VN:1.6→SO:unsorted
@sq→SN:chr1→LN:1000
r1→4→*→0→0→*→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM002]: `@sq` is not a header record type
 --> example.sam:2:1
  |
2 | @sq→SN:chr1→LN:1000
  | ^^^
  = help: record types are upper case: write `@SQ`
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM002`, or check only this rule with `--select SAM002`.
