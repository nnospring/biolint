# VCF217: FILTER name is not declared in the header

| | |
|---|---|
| Name | `filter-undeclared` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.4.3 |

Each filter used in records should have a `##FILTER=<ID=...>` line. htslib adds a placeholder and warns; BCF cannot store an undeclared filter. Reported once per name.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→LowQual→.
```

biolint reports:

```text
warning[VCF217]: filter `LowQual` has no `##FILTER` line
 --> example.vcf:3:15
  |
3 | 1→100→.→A→T→.→LowQual→.
  |               ^^^^^^^
  = help: add `##FILTER=<ID=LowQual,Description="...">` to the header
  = spec: VCF 4.3 §1.4.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF217`, or check only this rule with `--select VCF217`.
