# SAM004: Header tag or value does not match the required pattern

| | |
|---|---|
| Name | `header-field-irregular` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

A header tag is a letter followed by a letter or digit, and its value is at least one printable ASCII character. Only the `DS` and `CL` values and `@CO` lines may contain other (UTF-8) characters, and a `@CO` line needs a tab after `@CO`. samtools keeps such fields as they are.

## Example

Empty value:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→AS:
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM004]: `AS:` has an empty value
 --> example.sam:2:21
  |
2 | @SQ→SN:chr1→LN:1000→AS:
  |                     ^^^
  = help: give it a value or delete the field
  = spec: SAM v1 §1.3
```

A tag starts with a letter:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→1A:x
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM004]: header tag `1A` is not a letter followed by a letter or digit
 --> example.sam:2:21
  |
2 | @SQ→SN:chr1→LN:1000→1A:x
  |                     ^^
  = help: predefined tags are two upper-case letters; use lower case for your own
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM004`, or check only this rule with `--select SAM004`.
