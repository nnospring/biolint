# GFF214: Is_circular is not "true"

| | |
|---|---|
| Name | `is-circular-invalid` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Circular Genomes |

`Is_circular=true` on the feature that represents a whole chromosome or plasmid marks it as circular, which allows features to cross its origin. It is a flag: the value is `true` (or `false`), in lower case.

## Example

```text
##gff-version 3
pX01→example→region→1→4821→.→+→.→ID=pX01;Is_circular=yes
```

biolint reports:

```text
warning[GFF214]: Is_circular value `yes` is not `true`
 --> example.gff3:2:54
  |
2 | pX01→example→region→1→4821→.→+→.→ID=pX01;Is_circular=yes
  |                                                      ^^^
  = help: write `Is_circular=true`, in lower case
  = spec: GFF3 1.26, Circular Genomes
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region pX01 1 4821
pX01→example→region→1→4821→.→+→.→ID=pX01;Is_circular=true
pX01→example→CDS→4500→5120→.→+→0→ID=cds1;Name=repA
```

## Configuration

Silence it with `--ignore GFF214`, or check only this rule with `--select GFF214`.
