# GTF001: Feature line does not have nine tab-separated columns

| | |
|---|---|
| Name | `column-count` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, Introduction |

Every feature line has nine columns separated by single tab characters: seqname, source, feature, start, end, score, strand, frame, attributes. The attributes in column 9 are separated from each other by spaces, so parsers split the line on tabs only. The usual cause is an editor or a copy-paste that turned the tabs into spaces.

## Example

Separated by spaces:

```text
chr1 example exon 150 200 . + . gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF001]: line has 1 column, expected 9
 --> example.gtf:1:69
  |
1 | chr1 example exon 150 200 . + . gene_id "g1"; transcript_id "g1.t1";
  |                                                                     ^
  = help: the fields are separated by spaces; GTF columns must be separated by single tab characters (a text editor or copy-paste often converts tabs to spaces)
  = spec: GTF 2.2, Introduction
```

No attributes column:

```text
chr1→example→exon→1200→1350→.→+→.
```

biolint reports:

```text
error[GTF001]: line has 8 columns, expected 9
 --> example.gtf:1:34
  |
1 | chr1→example→exon→1200→1350→.→+→.
  |                                  ^
  = help: the attributes column is missing; write `.` in column 9 if a feature has no attributes
  = spec: GTF 2.2, Introduction
```

In these listings `→` stands for a tab.

## Accepted

```text
chr2→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr2→example→CDS→1299→1350→.→+→0→gene_id "g1"; transcript_id "g1.t1";
chr2→example→start_codon→1299→1301→.→+→0→gene_id "g1"; transcript_id "g1.t1";
chr2→example→exon→1500→1618→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr2→example→CDS→1500→1618→.→+→2→gene_id "g1"; transcript_id "g1.t1";
chr2→example→exon→1800→2100→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr2→example→CDS→1800→1898→.→+→0→gene_id "g1"; transcript_id "g1.t1";
chr2→example→stop_codon→1899→1901→.→+→0→gene_id "g1"; transcript_id "g1.t1";
```

## Configuration

Silence it with `--ignore GTF001`, or check only this rule with `--select GTF001`.
