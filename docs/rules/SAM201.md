# SAM201: Optional field is not TAG:TYPE:VALUE

| | |
|---|---|
| Name | `aux-malformed` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.5 |

Fields after the eleventh are `TAG:TYPE:VALUE`: a two-character tag, a one-letter type and a value, for example `NM:i:2`. A missing type (`NM:2`), a tag of another length or an empty field between two tabs stops samtools with "incomplete aux field". (samtools does not look at the character after the type, so it reads `ML:B,C,1` as `ML:B:C,1`; the field is reported all the same.)

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:2
```

biolint reports:

```text
error[SAM201]: optional field `NM:2` is not `TAG:TYPE:VALUE`
 --> example.sam:3:38
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:2
  |                                      ^^^^
  = help: the type is missing: write `NM:i:2`
  = spec: SAM v1 §1.5
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:2→→AS:i:5
```

biolint reports:

```text
error[SAM201]: empty optional field between two tabs
 --> example.sam:3:44
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:2→→AS:i:5
  |                                            ^^
  = help: remove the extra tab
  = spec: SAM v1 §1.5
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:2→XS:A:+→de:f:0.02→MD:Z:5→XH:H:1AE301→ZB:B:s,-5,12→CO:Z:
```

## Configuration

Silence it with `--ignore SAM201`, or check only this rule with `--select SAM201`.
