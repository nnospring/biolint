# VCF006: Structured meta line has no ID

| | |
|---|---|
| Name | `meta-id-missing` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4 |

Every structured line (`##INFO`, `##FORMAT`, `##FILTER`, `##ALT`, `##contig`, `##SAMPLE`, ...) is identified by its `ID`. Without one it cannot be referred to from records.

## Example

```text
##fileformat=VCFv4.3
##FILTER=<Description="Low quality">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF006]: `##FILTER` line has no `ID`
 --> example.vcf:2:10
  |
2 | ##FILTER=<Description="Low quality">
  |          ^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: add `ID=<name>` as the first entry
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF006`, or check only this rule with `--select VCF006`.
