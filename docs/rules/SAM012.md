# SAM012: @SQ LN exceeds 2^31-1

| | |
|---|---|
| Name | `sq-length-too-large` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

The specification limits reference lengths to 2,147,483,647 bases, the largest value BAM and its BAI index can hold. samtools reads longer references from SAM text, but the file cannot be converted to BAM, and BAI indexing already stops at 2^29 (use a CSI index).

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:3000000000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM012]: reference length 3000000000 is larger than 2147483647 (2^31-1)
 --> example.sam:2:16
  |
2 | @SQ→SN:chr1→LN:3000000000
  |                ^^^^^^^^^^
  = help: check the value; a reference this long cannot be stored in BAM
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM012`, or check only this rule with `--select SAM012`.
