# BED020: Chromosome name has characters outside letters, digits and underscore

| | |
|---|---|
| Name | `chrom-name` |
| Format | BED |
| Level | `off` by default, `error` with `--strict` |
| Source | BED v1.0 §1.5, §1.6 |

The specification restricts chromosome names to 1–255 letters, digits and underscores so that files are portable between tools. Real genomes break this rule all the time (`MT192765.1`, `HLA-A*01:01`, `NC_000001.11`), and tools accept such names, so this is only checked in the strict profile.

## Example

```text
NC_000001.11→1000→5000
```

biolint reports:

```text
error[BED020]: chrom `NC_000001.11` contains `.`; the specification allows only letters, digits and `_`
 --> example.bed:1:10
  |
1 | NC_000001.11→1000→5000
  |          ^
  = help: most tools accept such names; the restriction exists for portability and is only enforced in the strict profile
  = spec: BED v1.0 §1.5, §1.6
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED020`, or check only this rule with `--select BED020`.
