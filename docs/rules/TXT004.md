# TXT004: Mixed LF and CRLF line endings

| | |
|---|---|
| Name | `mixed-line-endings` |
| Format | Any format |
| Level | `warning` |
| Fixable | yes, with `biolint --fix` |

Some lines end with LF and others with CRLF, typically after concatenating files edited on different systems.

## Example

```text
>seq1␍
ACGT
>seq2
ACGT
```

biolint reports:

```text
warning[TXT004]: 1 line end with CRLF and 3 lines end with LF
 --> example.fasta
  = help: normalise to LF with `biolint --fix` or `dos2unix`
  = fix: Convert all line endings to LF (--fix)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore TXT004`, or check only this rule with `--select TXT004`.
