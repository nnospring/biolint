# TXT020: Could not determine the file format

| | |
|---|---|
| Name | `unknown-format` |
| Format | Any format |
| Level | `error` |

Neither the file name nor the content identifies a supported format. Pass `--type` to say which format the file is meant to be.

## Configuration

Silence it with `--ignore TXT020`, or check only this rule with `--select TXT020`.
