# GFF001: File does not declare ##gff-version 3

| | |
|---|---|
| Name | `version-missing` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Other Syntax: ##gff-version |

A GFF3 file must begin with the line `##gff-version 3`. The extension `.gff` is shared by GFF3, GFF2 and GTF, which differ in how column 9 is written, so this line is the only reliable way for a program to know which one it has. Most tools assume GFF3 when it is missing, which is why this is a warning by default; GenomeTools and other strict parsers refuse the file. It usually goes missing when a file is filtered with `grep -v "^#"` or assembled by a script.

## Example

```text
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
warning[GFF001]: the file does not start with `##gff-version 3`
 --> example.gff3:1
  = help: insert `##gff-version 3` as the first line
  = note: checking the file as GFF3
  = spec: GFF3 1.26, Other Syntax: ##gff-version
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region chr1 1 50000
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Name=abcA
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
chr1→example→exon→2100→2600→.→+→.→Parent=tx1
chr1→example→exon→4000→7400→.→+→.→Parent=tx1
chr1→example→CDS→2300→2600→.→+→0→ID=cds1;Parent=tx1
chr1→example→CDS→4000→4701→.→+→2→ID=cds1;Parent=tx1
```

## Configuration

Silence it with `--ignore GFF001`, or check only this rule with `--select GFF001`.
