# SAM008: @HD has no valid VN

| | |
|---|---|
| Name | `hd-version-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

The `@HD` line must carry the format version as `VN:major.minor`, digits on both sides of one dot, for example `VN:1.6`. samtools does not check it.

## Example

```text
@HD→VN:1→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM008]: `VN:1` is not a version of the form major.minor
 --> example.sam:1:8
  |
1 | @HD→VN:1→SO:unsorted
  |        ^
  = help: write `VN:1.0`
  = spec: SAM v1 §1.3
```

```text
@HD→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM008]: `@HD` has no `VN` (format version)
 --> example.sam:1:1
  |
1 | @HD→SO:unsorted
  | ^^^
  = help: add `VN:1.6`
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM008`, or check only this rule with `--select SAM008`.
