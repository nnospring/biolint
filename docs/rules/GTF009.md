# GTF009: Coding feature has no frame

| | |
|---|---|
| Name | `frame-missing` |
| Format | GTF |
| Level | `warning` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: <feature>, <frame> |

A `CDS` line needs a frame of 0, 1 or 2; without it a program cannot translate a transcript whose first CDS segment does not begin with a complete codon. GTF 2.2 also requires a frame on every `start_codon` and `stop_codon` line. Practice differs: some producers write `.` for start and stop codons, and tools in common use do not read their frame, so the default profile checks only `CDS` and the strict profile checks all three.

## Example

```text
chr1→example→CDS→1299→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
warning[GTF009]: CDS feature has no frame
 --> example.gtf:1:32
  |
1 | chr1→example→CDS→1299→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
  |                                ^
  = help: write 0, 1 or 2: the number of bases before the first complete codon of this segment, counted from its 5' end (0 for the segment that begins with the start codon)
  = spec: GTF 2.2, GTF Field Definitions: <feature>, <frame>
```

Strict only: a start codon without a frame:

```text
chr1→example→start_codon→1299→1301→.→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF009]: start_codon feature has no frame
 --> example.gtf:1:40
  |
1 | chr1→example→start_codon→1299→1301→.→+→.→gene_id "g1"; transcript_id "g1.t1";
  |                                        ^
  = help: write 0 for a codon in one piece; for a codon split by an intron, the number of its bases that precede this piece
  = spec: GTF 2.2, GTF Field Definitions: <feature>, <frame>
```

In these listings `→` stands for a tab.

## Accepted

```text
chr2→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr2→example→CDS→1299→1350→.→+→0→gene_id "g1"; transcript_id "g1.t1";
chr2→example→start_codon→1299→1301→.→+→0→gene_id "g1"; transcript_id "g1.t1";
chr2→example→exon→1500→1618→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr2→example→CDS→1500→1618→.→+→2→gene_id "g1"; transcript_id "g1.t1";
chr2→example→exon→1800→2100→.→+→.→gene_id "g1"; transcript_id "g1.t1";
chr2→example→CDS→1800→1898→.→+→0→gene_id "g1"; transcript_id "g1.t1";
chr2→example→stop_codon→1899→1901→.→+→0→gene_id "g1"; transcript_id "g1.t1";
```

## Configuration

Silence it with `--ignore GTF009`, or check only this rule with `--select GTF009`.
