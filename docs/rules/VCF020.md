# VCF020: ALT definition does not use a defined structural variant type

| | |
|---|---|
| Name | `alt-type-unknown` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.2 §1.2.5 |

The first colon-separated component of a structural-variant `##ALT` ID must be `DEL`, `INS`, `DUP`, `INV` or `CNV`. VCF 4.1 and 4.2 apply this to every `##ALT` line; from 4.3 other symbolic alleles may use their own names, so only IDs written as `type:subtype` are checked.

## Example

```text
##fileformat=VCFv4.2
##ALT=<ID=DELETION,Description="A deletion">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→<DELETION>→.→.→.
```

biolint reports:

```text
warning[VCF020]: ALT type `DELETION` is not one of the structural variant types the specification defines
 --> example.vcf:2:11
  |
2 | ##ALT=<ID=DELETION,Description="A deletion">
  |           ^^^^^^^^
  = help: did you mean `DEL`? a subtype goes after a colon, e.g. `DEL:ME`
  = spec: VCF 4.2 §1.2.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF020`, or check only this rule with `--select VCF020`.
