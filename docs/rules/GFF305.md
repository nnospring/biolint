# GFF305: Parent relationships form a cycle

| | |
|---|---|
| Name | `parent-cycle` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Parent (part_of) Relationships |

A feature cannot be part of itself, directly or through other features. Programs that walk from a feature to its parents never finish on such a file, so parsers are required to reject it. The simplest case is a feature whose `Parent` is its own `ID`.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Parent=gene1
```

biolint reports:

```text
error[GFF305]: feature `gene1` names itself as its Parent
 --> example.gff3:2:51
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1;Parent=gene1
  |                                                   ^^^^^
  = help: a gene and its transcript need different IDs: give the child its own ID and keep `Parent` pointing at the gene
  = spec: GFF3 1.26, Parent (part_of) Relationships
```

Two features that are each other's parent:

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Parent=tx1
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
```

biolint reports:

```text
error[GFF305]: Parent relationships form a cycle through the features on lines 2, 3
 --> example.gff3:2
  = help: follow the `Parent` values from this line: one of them points back at a feature that is its own descendant
  = spec: GFF3 1.26, Parent (part_of) Relationships
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF305`, or check only this rule with `--select GFF305`.
