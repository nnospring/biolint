# VCF209: Invalid ID

| | |
|---|---|
| Name | `id-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

ID is `.` or a semicolon-separated list of identifiers without whitespace, with no empty or repeated entries.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→rs1;;rs2→A→T→.→.→.
```

biolint reports:

```text
error[VCF209]: ID has an empty entry (stray `;`)
 --> example.vcf:3:7
  |
3 | 1→100→rs1;;rs2→A→T→.→.→.
  |       ^^^^^^^^
  = help: remove the extra semicolon
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF209`, or check only this rule with `--select VCF209`.
