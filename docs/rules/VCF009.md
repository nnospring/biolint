# VCF009: Invalid Number in INFO/FORMAT definition

| | |
|---|---|
| Name | `meta-number-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.2 |

`Number` is a non-negative integer, or `A` (one per ALT allele), `R` (one per allele including REF, from 4.2), `G` (one per genotype) or `.` (varies). VCF 4.4 adds `P`, and 4.5 adds `LA`, `LR`, `LG` and `M`, for FORMAT only.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=AF,Number=alt,Type=Float,Description="Allele frequency">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→AF=0.5
```

biolint reports:

```text
error[VCF009]: `Number=alt` is not a valid Number
 --> example.vcf:2:22
  |
2 | ##INFO=<ID=AF,Number=alt,Type=Float,Description="Allele frequency">
  |                      ^^^
  = help: use a non-negative integer, `A`, `R`, `G` or `.`
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF009`, or check only this rule with `--select VCF009`.
