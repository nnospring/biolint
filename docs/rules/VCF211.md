# VCF211: REF contains an IUPAC ambiguity code

| | |
|---|---|
| Name | `ref-ambiguous` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.6.1 |

Only `A`, `C`, `G`, `T`, `N` are allowed in REF. Where the reference has another IUPAC code, it must be reduced to the first base alphabetically (`R` becomes `A`). `bcftools norm --check-ref s` repairs this.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→R→T→.→.→.
```

biolint reports:

```text
warning[VCF211]: REF contains the IUPAC ambiguity code `R`
 --> example.vcf:3:9
  |
3 | 1→100→.→R→T→.→.→.
  |         ^
  = help: only A, C, G, T and N are allowed: use the alphabetically first base the code stands for (`bcftools norm --check-ref s` does this)
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF211`, or check only this rule with `--select VCF211`.
