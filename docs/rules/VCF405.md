# VCF405: Invalid genotype

| | |
|---|---|
| Name | `gt-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.2 |

GT is allele indices separated by `/` (unphased) or `|` (phased), with `.` for a missing allele: `0/1`, `1|0`, `./.`, `1`. Each index must refer to REF (0) or an existing ALT allele.

## Example

Allele 2 does not exist: the record has one ALT allele:

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT→0/2
```

biolint reports:

```text
error[VCF405]: genotype refers to allele 2, but the record has 1 ALT allele
 --> example.vcf:4:24
  |
4 | 1→100→.→A→T→.→.→.→GT→0/2
  |                        ^
  = help: allele indices run from 0 (REF) to 1
  = spec: VCF 4.3 §1.6.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF405`, or check only this rule with `--select VCF405`.
