# GFF110: Phase is not 0, 1, 2 or a dot

| | |
|---|---|
| Name | `phase-invalid` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Column 8: "phase" |

The phase is the number of bases (0, 1 or 2) to skip from the 5' end of a CDS segment to reach the first complete codon, or `.` for features that are not coding. It is not the reading frame (which can be written 1-3 or -1 to -3 in other formats).

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
chr1→example→CDS→2300→2600→.→+→3→Parent=gene1
```

biolint reports:

```text
error[GFF110]: phase `3` is not 0, 1, 2 or `.`
 --> example.gff3:3:32
  |
3 | chr1→example→CDS→2300→2600→.→+→3→Parent=gene1
  |                                ^
  = help: this looks like a reading frame; the phase is the number of bases (0, 1 or 2) before the first complete codon of the segment
  = spec: GFF3 1.26, Column 8: "phase"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF110`, or check only this rule with `--select GFF110`.
