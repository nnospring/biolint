# GFF209: Attribute value is wrapped in double quotes

| | |
|---|---|
| Name | `quoted-value` |
| Format | GFF3 |
| Level | `info` by default, `warning` with `--strict` |
| Source | GFF3 1.26, Column 9: "attributes" |

GFF3 values are not quoted. Quotes are kept as part of the value, so `product="kinase"` yields a product name that begins and ends with a quote character. They are a leftover of a conversion from GTF or GenBank; remove them and percent-encode `;`, `=`, `&` and `,` inside the text instead.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;product="protein kinase"
```

biolint reports:

```text
info[GFF209]: the value of `product` is wrapped in double quotes
 --> example.gff3:2:52
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1;product="protein kinase"
  |                                                    ^^^^^^^^^^^^^^^^
  = help: remove the quotes: GFF3 keeps them as part of the value
  = spec: GFF3 1.26, Column 9: "attributes"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF209`, or check only this rule with `--select GFF209`.
