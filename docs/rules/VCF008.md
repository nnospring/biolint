# VCF008: Meta line lacks a required field

| | |
|---|---|
| Name | `meta-field-missing` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.2 |

`##INFO` and `##FORMAT` need `ID`, `Number`, `Type` and `Description`; `##FILTER` and `##ALT` need `ID` and `Description`. htslib rejects INFO/FORMAT definitions without Number or Type.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
error[VCF008]: `##INFO` line has no `Number`
 --> example.vcf:2:8
  |
2 | ##INFO=<ID=DP,Type=Integer,Description="Total depth">
  |        ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: add `Number=...` after the ID
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF008`, or check only this rule with `--select VCF008`.
