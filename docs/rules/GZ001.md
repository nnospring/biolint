# GZ001: Compressed stream is truncated or corrupt

| | |
|---|---|
| Name | `gzip-truncated` |
| Format | Any format |
| Level | `error` |

Decompression stopped before the end of the gzip stream. The file was cut off (interrupted download or copy, full disk, job killed while writing) or damaged. Everything that could be decompressed was still checked.

## Configuration

Silence it with `--ignore GZ001`, or check only this rule with `--select GZ001`.
