# BED012: Standard field is empty

| | |
|---|---|
| Name | `empty-field` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.5 |

A standard BED field that is filled on one line must not be empty on another. Two tabs in a row leave an empty value between them; tools either reject the line or shift the remaining values one column to the left. Write `.` for an unknown name or strand and `0` for an unknown score.

## Example

```text
chr1→1000→5000→geneA→0→+
chr1→7000→7250→→0→-
```

biolint reports:

```text
error[BED012]: name is empty
 --> example.bed:2:16
  |
2 | chr1→7000→7250→→0→-
  |                ^
  = help: write `.` when a feature has no name
  = note: 6 fields per line, all read as standard fields (BED6, inferred from line 1); if column 4 is a custom field instead, declare it with `--option bed.type=bed3+3`
  = spec: BED v1.0 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED012`, or check only this rule with `--select BED012`.
