# SAM006: Tag appears twice in one header line

| | |
|---|---|
| Name | `header-tag-duplicate` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

Within one header line each tag may be used once. With two values for the same tag, tools disagree on which one counts; samtools refuses the line only when two `LN` values differ.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→AS:hg19→AS:hg38
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM006]: `AS` appears twice in this `@SQ` line (`hg19` and `hg38`)
 --> example.sam:2:29
  |
2 | @SQ→SN:chr1→LN:1000→AS:hg19→AS:hg38
  |                             ^^
  = help: keep one of them
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM006`, or check only this rule with `--select SAM006`.
