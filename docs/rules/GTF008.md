# GTF008: Frame is not 0, 1, 2 or a dot

| | |
|---|---|
| Name | `frame-invalid` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: <frame> |

The frame of a coding feature is 0, 1 or 2: the number of bases before its first complete codon, counted from the 5' end. Other features have `.`. Values such as 3 or -1 are reading frames from another convention.

## Example

```text
chr1→example→CDS→1299→1350→.→+→3→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF008]: frame `3` is not 0, 1, 2 or `.`
 --> example.gtf:1:32
  |
1 | chr1→example→CDS→1299→1350→.→+→3→gene_id "g1"; transcript_id "g1.t1";
  |                                ^
  = help: this looks like a reading frame from another convention; the GTF frame is the number of bases (0, 1 or 2) before the first complete codon
  = spec: GTF 2.2, GTF Field Definitions: <frame>
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF008`, or check only this rule with `--select GTF008`.
