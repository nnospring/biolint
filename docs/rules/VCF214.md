# VCF214: ALT repeats an allele or equals REF

| | |
|---|---|
| Name | `alt-duplicate` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.6.1 |

The ALT list holds distinct non-reference alleles. A repeated allele, or one identical to REF, makes allele indices and per-allele annotations (`AC`, `AF`, `AD`) ambiguous.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T,T→.→.→.
```

biolint reports:

```text
warning[VCF214]: ALT allele `T` is listed twice
 --> example.vcf:3:13
  |
3 | 1→100→.→A→T,T→.→.→.
  |             ^
  = help: list each alternate allele once
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF214`, or check only this rule with `--select VCF214`.
