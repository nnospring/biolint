# BED045: Blocks overlap or are not in ascending order

| | |
|---|---|
| Name | `block-overlap` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.9 |

Blocks are listed from left to right along the chromosome, on both strands, and may touch but not overlap. For minus-strand transcripts the exons must still be written in ascending coordinate order, not in transcript order.

## Example

```text
chr22→1000→5000→cloneA→960→-→1000→5000→0→2→1488,567→3512,0
```

biolint reports:

```text
error[BED045]: blockStarts begins with `3512` and continues with smaller values: blocks are not in ascending order
 --> example.bed:1:53
  |
1 | chr22→1000→5000→cloneA→960→-→1000→5000→0→2→1488,567→3512,0
  |                                                     ^^^^^^
  = help: list blocks from left to right along the chromosome, also for features on the minus strand (reverse both lists)
  = note: column 12 is read as blockStarts because the columns to its right on this line fit the standard fields that follow it; if column 12 is a custom field instead, declare it with `--option bed.type=bed9+3`
  = spec: BED v1.0 §1.9
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED045`, or check only this rule with `--select BED045`.
