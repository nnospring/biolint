# GZ002: BGZF end-of-file marker is missing

| | |
|---|---|
| Name | `bgzf-no-eof` |
| Format | Any format |
| Level | `warning` |
| Source | SAM v1 §4.1.2 |

A complete BGZF file ends with a fixed 28-byte empty block. Its absence is how samtools and htslib detect truncated files ("EOF marker is absent"). The writer was probably interrupted; regenerate the file.

## Configuration

Silence it with `--ignore GZ002`, or check only this rule with `--select GZ002`.
