# SAM114: CIGAR is malformed

| | |
|---|---|
| Name | `cigar-invalid` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

A CIGAR is `*` or a series of length-operation pairs such as `76M` or `5S60M2D11M`. The operations are `M I D N S H P = X`, in upper case, each preceded by its length, and a length must be below 2^28 (the BAM limit). samtools stops at an unknown operation, a missing length or a trailing number. (The obsolete `B` operation, which samtools still reads, is reported separately.)

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5m→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM114]: CIGAR `5m` contains `m`, which is not a CIGAR operation
 --> example.sam:3:18
  |
3 | r1→0→chr1→10→30→5m→*→0→0→ACGTA→IIIII
  |                  ^
  = help: operations are upper case: write `M`
  = spec: SAM v1 §1.4
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→M5→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM114]: CIGAR `M5` has operation `M` without a length
 --> example.sam:3:17
  |
3 | r1→0→chr1→10→30→M5→*→0→0→ACGTA→IIIII
  |                 ^
  = help: the length comes before the operation: `5M`, not `M5`
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM114`, or check only this rule with `--select SAM114`.
