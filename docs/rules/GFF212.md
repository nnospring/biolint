# GFF212: Target is not "target_id start end [strand]"

| | |
|---|---|
| Name | `target-invalid` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Column 9: "attributes" (Target) |

The `Target` of an alignment is the name of the aligned sequence, its start and end in that sequence, and optionally a strand, separated by single spaces: `Target=mrna0042 1 448 +`. Start is not after end; the direction is given by the strand, not by swapping the coordinates. Old files join the parts with `+` instead of spaces, which is no longer allowed. GenomeTools rejects a Target that does not have three or four parts, or whose start is after its end.

## Example

```text
##gff-version 3
scaffold7→aligner→cDNA_match→2001→2460→.→+→.→ID=aln1;Target=mrna0042
```

biolint reports:

```text
warning[GFF212]: Target `mrna0042` is not `target_id start end [strand]`
 --> example.gff3:2:61
  |
2 | scaffold7→aligner→cDNA_match→2001→2460→.→+→.→ID=aln1;Target=mrna0042
  |                                                             ^^^^^^^^
  = help: the start and end of the alignment in the target sequence are missing, e.g. `Target=mrna0042 1 448`
  = spec: GFF3 1.26, Column 9: "attributes" (Target)
```

The deprecated `+` separator:

```text
##gff-version 3
scaffold7→aligner→cDNA_match→2001→2460→.→+→.→ID=aln1;Target=mrna0042+1+448
```

biolint reports:

```text
warning[GFF212]: Target `mrna0042+1+448` is not `target_id start end [strand]`
 --> example.gff3:2:61
  |
2 | scaffold7→aligner→cDNA_match→2001→2460→.→+→.→ID=aln1;Target=mrna0042+1+448
  |                                                             ^^^^^^^^^^^^^^
  = help: joining the parts with `+` is no longer allowed; write `Target=mrna0042 1 448`
  = spec: GFF3 1.26, Column 9: "attributes" (Target)
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
scaffold7→aligner→cDNA_match→2001→2460→97.5→+→.→ID=aln1;Target=mrna0042 1 448;Gap=M210 D12 M238
scaffold7→aligner→cDNA_match→6100→6385→3.1e-30→-→.→ID=aln2;Target=mrna0077 15 300 +
scaffold7→aligner→cDNA_match→7020→7339→2.4e-35→-→.→ID=aln2;Target=mrna0077 301 620 +
```

## Configuration

Silence it with `--ignore GFF212`, or check only this rule with `--select GFF212`.
