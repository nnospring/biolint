# VCF007: Two meta lines of the same kind share an ID

| | |
|---|---|
| Name | `meta-id-duplicate` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4 |

IDs must be unique among lines with the same `##key=` prefix. With duplicates, which definition a parser keeps is implementation-defined: htslib keeps the first and warns. Duplicates usually come from merging headers by hand.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth">
##INFO=<ID=DP,Number=1,Type=Float,Description="Depth again">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
error[VCF007]: `##INFO` ID `DP` is already defined
 --> example.vcf:3:12
  |
3 | ##INFO=<ID=DP,Number=1,Type=Float,Description="Depth again">
  |            ^^
  = help: keep one definition and delete the other
  = note: first defined on line 2
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF007`, or check only this rule with `--select VCF007`.
