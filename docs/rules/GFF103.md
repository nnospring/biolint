# GFF103: Empty column

| | |
|---|---|
| Name | `empty-field` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Description of the Format |

A column may not be left empty: a value that is unknown or does not apply is written as a single `.`. Empty columns appear when a script joins fields that contain missing values, and parsers that split on runs of whitespace then see a shifted line.

## Example

```text
##gff-version 3
chr1→→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
warning[GFF103]: the source column is empty
 --> example.gff3:2:6
  |
2 | chr1→→gene→2100→7400→.→+→.→ID=gene1
  |      ^
  = help: write `.` for a value that is unknown or does not apply
  = spec: GFF3 1.26, Description of the Format
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF103`, or check only this rule with `--select GFF103`.
