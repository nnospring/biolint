# BED003: browser or track line after data lines

| | |
|---|---|
| Name | `track-line-misplaced` |
| Format | BED |
| Level | `warning` by default, `error` with `--strict` |
| Source | BED v1.0 §5 |

Browser and track lines belong before the data. A `track` line in the middle starts a second track, which only the UCSC Genome Browser understands; a `browser` line in the middle has no defined meaning. This is usually the result of joining two custom-track files with `cat`. biolint checks each track separately from this point on.

## Example

```text
chr1→1000→5000
browser position chr1:1-10000
chr1→7000→7250
```

biolint reports:

```text
warning[BED003]: `browser` line after data lines
 --> example.bed:2:1
  |
2 | browser position chr1:1-10000
  | ^^^^^^^
  = help: move `browser` lines to the top of the file, or delete them
  = spec: BED v1.0 §5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED003`, or check only this rule with `--select BED003`.
