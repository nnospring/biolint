# SAM009: Invalid SO, GO or SS value in @HD

| | |
|---|---|
| Name | `hd-sort-order-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

`SO` is one of `unknown`, `unsorted`, `queryname` or `coordinate`; `GO` is one of `none`, `query` or `reference`; `SS` is the `SO` value followed by one or more `:term` parts. The values are case-sensitive keywords: `SO:sorted` or `SO:Coordinate` is not one of them, so a tool that looks for `SO:coordinate` does not find it.

## Example

```text
@HD→VN:1.6→SO:sorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM009]: `SO:sorted` is not a sort order
 --> example.sam:1:15
  |
1 | @HD→VN:1.6→SO:sorted
  |               ^^^^^^
  = help: did you mean `SO:coordinate`? the value is one of unknown, unsorted, queryname or coordinate
  = spec: SAM v1 §1.3
```

```text
@HD→VN:1.6→GO:queryname
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM009]: `GO:queryname` is not a grouping
 --> example.sam:1:15
  |
1 | @HD→VN:1.6→GO:queryname
  |               ^^^^^^^^^
  = help: did you mean `GO:query`? the value is one of none, query or reference
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM009`, or check only this rule with `--select SAM009`.
