# VCF502: File has a header but no records

| | |
|---|---|
| Name | `no-records` |
| Format | VCF |
| Level | `info` |

The file is a valid header with zero variants. That is legitimate (an empty region, a sample with no calls), but it is also what a silently failed caller leaves behind.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
```

biolint reports:

```text
info[VCF502]: the file has a header but no variant records
 --> example.vcf
  = help: fine if no variants are expected here; otherwise check the step that produced the file
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF502`, or check only this rule with `--select VCF502`.
