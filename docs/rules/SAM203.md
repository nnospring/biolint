# SAM203: Optional field tag is not a letter followed by a letter or digit

| | |
|---|---|
| Name | `aux-tag-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.5 |

Tags are exactly two characters: a letter, then a letter or digit (`NM`, `X0`, `tp`). samtools keeps other tags as they are.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→1A:i:5
```

biolint reports:

```text
warning[SAM203]: tag `1A` is not a letter followed by a letter or digit
 --> example.sam:3:38
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→1A:i:5
  |                                      ^^
  = help: rename the tag; lower-case tags and tags starting with X, Y or Z are free for your own use
  = spec: SAM v1 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM203`, or check only this rule with `--select SAM203`.
