# VCF105: Column header line appears again

| | |
|---|---|
| Name | `header-repeated` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.5 |

A second `#CHROM` line in the body means files were concatenated with `cat`. The second file's samples and definitions may differ; use `bcftools concat` (same samples) or `bcftools merge` (different samples).

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→200→.→G→C→.→.→.
```

biolint reports:

```text
error[VCF105]: a second column header line
 --> example.vcf:4:1
  |
4 | #CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: the file looks like several VCFs joined with `cat`; use `bcftools concat` (same samples) or `bcftools merge`
  = note: the first column header is on line 2
  = spec: VCF 4.3 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF105`, or check only this rule with `--select VCF105`.
