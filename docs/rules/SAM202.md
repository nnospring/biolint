# SAM202: Alignment line ends with a tab

| | |
|---|---|
| Name | `trailing-tab` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.5 |

A tab at the end of the line starts an optional field that is empty. samtools ignores it; a parser that splits on tabs finds a field that is not `TAG:TYPE:VALUE`. Scripts that append a tab after every field cause this.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:0→
```

biolint reports:

```text
warning[SAM202]: the line ends with a tab, which starts an empty optional field
 --> example.sam:3:44
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:0→
  |                                            ^
  = help: remove the tab at the end of the line
  = spec: SAM v1 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM202`, or check only this rule with `--select SAM202`.
