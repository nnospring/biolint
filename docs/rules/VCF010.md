# VCF010: Invalid Type in INFO/FORMAT definition

| | |
|---|---|
| Name | `meta-type-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.2 |

`Type` is one of `Integer`, `Float`, `Flag`, `Character`, `String` for INFO, and the same without `Flag` for FORMAT. The names are case-sensitive and not abbreviated.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Int,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
error[VCF010]: Type=Int is not a valid INFO type
 --> example.vcf:2:29
  |
2 | ##INFO=<ID=DP,Number=1,Type=Int,Description="Total depth">
  |                             ^^^
  = help: did you mean `Type=Integer`?
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF010`, or check only this rule with `--select VCF010`.
