# BED030: Name contains a space

| | |
|---|---|
| Name | `name-whitespace` |
| Format | BED |
| Level | `warning` |
| Source | BED v1.0 §1.7, §3.2 |

A space in the name is allowed only when the whole file is separated by single tabs, and even then the specification advises against it, because parsers that split on any whitespace (awk, the UCSC tools) see two fields and shift every later column. Replace the space with `_`.

## Example

```text
chr1→1000→5000→my gene
```

biolint reports:

```text
warning[BED030]: name `my gene` contains a space
 --> example.bed:1:18
  |
1 | chr1→1000→5000→my gene
  |                  ^
  = help: write `my_gene`: tools that split on any whitespace would read the name as two fields
  = note: column 4 is read as name because the columns to its right on this line fit the standard fields that follow it; if column 4 is a custom field instead, declare it with `--option bed.type=bed3+1`
  = spec: BED v1.0 §1.7, §3.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED030`, or check only this rule with `--select BED030`.
