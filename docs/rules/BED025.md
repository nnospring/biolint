# BED025: Features are not sorted

| | |
|---|---|
| Name | `not-sorted` |
| Format | BED |
| Level | `info` by default, `warning` with `--strict` |
| Source | BED v1.0 §3.4 |

Sorting is recommended, not required: all lines of one chromosome together, ordered by start. Indexing with tabix, conversion to bigBed and the `-sorted` modes of bedtools need it. Sort with `sort -k1,1 -k2,2n -k3,3n` or `bedtools sort`. Reported once per file.

## Example

```text
chr1→7000→7250
chr1→1000→5000
```

biolint reports:

```text
info[BED025]: chromStart `1000` is smaller than `7000` on the previous line: the file is not sorted by position
 --> example.bed:2:6
  |
2 | chr1→1000→5000
  |      ^^^^
  = help: sort with `sort -k1,1 -k2,2n -k3,3n file.bed` or `bedtools sort -i file.bed` before indexing with tabix or using `bedtools -sorted`
  = spec: BED v1.0 §3.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED025`, or check only this rule with `--select BED025`.
