# SAM023: @RG PL is not written in upper case

| | |
|---|---|
| Name | `rg-platform-case` |
| Format | SAM |
| Level | `info` by default, `warning` with `--strict` |
| Source | SAM v1 §1.3 |

The platform names are defined in upper case (`ILLUMINA`, `ONT`, `PACBIO`, ...). The specification asks writers to use exactly that spelling and readers to accept lower case as well, because many public files contain `PL:illumina`; a tool that compares the value exactly will not recognise it.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@RG→ID:rg1→SM:sample1→PL:illumina
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:rg1
```

biolint reports:

```text
info[SAM023]: `PL:illumina` is not in upper case
 --> example.sam:3:26
  |
3 | @RG→ID:rg1→SM:sample1→PL:illumina
  |                          ^^^^^^^^
  = help: write `PL:ILLUMINA`
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM023`, or check only this rule with `--select SAM023`.
