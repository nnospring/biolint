# GFF108: Score is not a number

| | |
|---|---|
| Name | `score-invalid` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Column 6: "score" |

The score is a floating point number, or `.` when there is none. Readers convert the column to a number: HTSeq, for one, stops with a conversion error when it holds text such as `NA` or a decimal comma.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→0,95→+→.→ID=gene1
```

biolint reports:

```text
error[GFF108]: score `0,95` is not a number
 --> example.gff3:2:29
  |
2 | chr1→example→gene→2100→7400→0,95→+→.→ID=gene1
  |                             ^^^^
  = help: use a decimal point: `0.95`
  = spec: GFF3 1.26, Column 6: "score"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF108`, or check only this rule with `--select GFF108`.
