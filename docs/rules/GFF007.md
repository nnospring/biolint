# GFF007: Feature lies outside its ##sequence-region

| | |
|---|---|
| Name | `feature-outside-region` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Other Syntax: ##sequence-region |

When a `##sequence-region` is given for a sequence, every feature on it must lie inside that range. A feature beyond the end usually means the annotation and the directive come from different assemblies, or the file was cut from a larger one without adjusting the directive. The one exception is a circular sequence: when its landmark feature carries `Is_circular=true`, a feature that crosses the origin has an end beyond the sequence length.

## Example

```text
##gff-version 3
##sequence-region chr1 1 5000
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
warning[GFF007]: feature 2100-7400 lies outside `##sequence-region chr1 1 5000`
 --> example.gff3:3:24
  |
3 | chr1→example→gene→2100→7400→.→+→.→ID=gene1
  |                        ^^^^
  = help: the directive and the features probably come from different assemblies or a subset of the file; correct the directive or remove it
  = note: the region is declared on line 2
  = spec: GFF3 1.26, Other Syntax: ##sequence-region
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region pX01 1 4821
pX01→example→region→1→4821→.→+→.→ID=pX01;Is_circular=true
pX01→example→CDS→4500→5120→.→+→0→ID=cds1;Name=repA
```

## Configuration

Silence it with `--ignore GFF007`, or check only this rule with `--select GFF007`.
