# GTF005: Start is greater than end

| | |
|---|---|
| Name | `start-after-end` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: <start> <end> |

Start must be less than or equal to end, also on the minus strand: the strand column gives the direction, not the order of the coordinates. Tools that compute feature lengths get negative numbers from such a line, or skip it.

## Example

```text
chr1→example→exon→1350→1200→.→-→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF005]: start 1350 is greater than end 1200
 --> example.gtf:1:19
  |
1 | chr1→example→exon→1350→1200→.→-→.→gene_id "g1"; transcript_id "g1.t1";
  |                   ^^^^^^^^^
  = help: write the smaller coordinate first (start 1200, end 1350): the `-` in column 7 already says the feature is on the reverse strand
  = spec: GTF 2.2, GTF Field Definitions: <start> <end>
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF005`, or check only this rule with `--select GTF005`.
