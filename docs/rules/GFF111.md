# GFF111: CDS feature has no phase

| | |
|---|---|
| Name | `cds-phase-missing` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Column 8: "phase" |

Every CDS line needs a phase of 0, 1 or 2. Without it a program cannot translate a CDS whose first segment does not start with a complete codon, and tools that derive protein sequences either assume 0 or skip the feature. For a CDS in a single piece that starts at the start codon the phase is 0.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
chr1→example→CDS→2300→2600→.→+→.→Parent=gene1
```

biolint reports:

```text
warning[GFF111]: CDS feature has no phase
 --> example.gff3:3:32
  |
3 | chr1→example→CDS→2300→2600→.→+→.→Parent=gene1
  |                                ^
  = help: write 0, 1 or 2: the number of bases to skip at the 5' end of this segment to reach a complete codon (0 for a segment that begins with the start codon)
  = spec: GFF3 1.26, Column 8: "phase"
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region chr1 1 50000
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Name=abcA
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
chr1→example→exon→2100→2600→.→+→.→Parent=tx1
chr1→example→exon→4000→7400→.→+→.→Parent=tx1
chr1→example→CDS→2300→2600→.→+→0→ID=cds1;Parent=tx1
chr1→example→CDS→4000→4701→.→+→2→ID=cds1;Parent=tx1
```

## Configuration

Silence it with `--ignore GFF111`, or check only this rule with `--select GFF111`.
