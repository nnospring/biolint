# VCF408: Empty sample field

| | |
|---|---|
| Name | `sample-empty-field` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.2 |

A missing value inside a sample column is written `.`, never left empty (`0/1::20`).

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=DP,Number=1,Type=Integer,Description="Read depth">
##FORMAT=<ID=GQ,Number=1,Type=Integer,Description="Genotype quality">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT:DP:GQ→0/1::20
```

biolint reports:

```text
error[VCF408]: `DP` is empty in this sample
 --> example.vcf:6:31
  |
6 | 1→100→.→A→T→.→.→.→GT:DP:GQ→0/1::20
  |                               ^^
  = help: write `.` for a missing value
  = spec: VCF 4.3 §1.6.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF408`, or check only this rule with `--select VCF408`.
