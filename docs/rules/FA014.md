# FA014: Character is not a residue code

| | |
|---|---|
| Name | `non-residue-character` |
| Format | FASTA |
| Level | `warning` by default, `error` with `--strict` |
| Source | NCBI BLAST help, FASTA |

Besides letters, a sequence may contain `-` (a gap in an alignment) and `*` (a translation stop). Other punctuation is not part of FASTA: `.` and `~` are gap symbols of other alignment formats, `?` marks missing data in phylogenetics formats, and `&` joins two strands in ViennaRNA input. Some tools pass these characters through, others turn them into `N`/`X` or stop, so the result depends on the program.

## Example

`.` used as a gap symbol:

```text
>aln1
ACGT..ACGTACGT
```

biolint reports:

```text
warning[FA014]: `.` is not a residue code
 --> example.fasta:2:5
  |
2 | ACGT..ACGTACGT
  |     ^
  = help: `.` is the gap symbol of A2M/Stockholm alignments; FASTA alignments use `-`
  = spec: NCBI BLAST help, FASTA

warning[FA014]: `.` is not a residue code
 --> example.fasta:2:6
  |
2 | ACGT..ACGTACGT
  |      ^
  = help: `.` is the gap symbol of A2M/Stockholm alignments; FASTA alignments use `-`
  = spec: NCBI BLAST help, FASTA
```

In these listings `→` stands for a tab.

## Accepted

```text
>aln1
ACGT--ACGTACGT
>aln2
ACGTTTACGT--GT
```

## Configuration

Silence it with `--ignore FA014`, or check only this rule with `--select FA014`.
