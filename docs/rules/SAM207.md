# SAM207: Tag appears twice in one alignment line

| | |
|---|---|
| Name | `aux-tag-duplicate` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.5 |

Each tag may appear once per record. samtools keeps both copies, and a lookup by tag (tried with pysam) returns the first, so the second value is never seen. Pipelines that add a tag without removing the old one cause this.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:0→AS:i:5→NM:i:1
```

biolint reports:

```text
warning[SAM207]: tag `NM` appears more than once in this record
 --> example.sam:3:52
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:0→AS:i:5→NM:i:1
  |                                                    ^^
  = help: keep one copy: tools return the first and ignore the rest
  = spec: SAM v1 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM207`, or check only this rule with `--select SAM207`.
