# GTF003: Empty column

| | |
|---|---|
| Name | `empty-field` |
| Format | GTF |
| Level | `warning` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions |

A column may not be left empty: a score or frame that does not apply is written as a single `.`. Empty columns appear when a script joins fields that contain missing values, and parsers that split on runs of whitespace then read a shifted line.

## Example

```text
chr1→→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
warning[GTF003]: the source column is empty
 --> example.gtf:1:6
  |
1 | chr1→→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";
  |      ^
  = help: write `.` for a value that is unknown or does not apply
  = spec: GTF 2.2, GTF Field Definitions
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF003`, or check only this rule with `--select GTF003`.
