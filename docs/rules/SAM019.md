# SAM019: Header value does not have the format defined for its tag

| | |
|---|---|
| Name | `header-value-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

Some predefined header tags have a fixed format: `@SQ M5` is 32 lower-case hexadecimal digits, `TP` is `linear` or `circular`, `AH` is `*` or a locus such as `chr1:100-200`; `@RG DT` is an ISO 8601 date or date-time, `PI` a whole number, `FO` is `*` or IUPAC bases. samtools does not check these when reading a header; a malformed `M5`, for example, can never equal the checksum of the sequence.

## Example

M5 is written in lower case:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→M5:7FC56270E7A70FA81A5935B72EACBE29
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM019]: `M5:7FC56270E7A70FA81A5935B72EACBE29` is not an MD5 digest in lower-case hexadecimal
 --> example.sam:2:24
  |
2 | @SQ→SN:chr1→LN:1000→M5:7FC56270E7A70FA81A5935B72EACBE29
  |                        ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: write it in lower case: `M5:7fc56270e7a70fa81a5935b72eacbe29`
  = spec: SAM v1 §1.3.2
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@RG→ID:rg1→SM:sample1→DT:23/06/2020
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:rg1
```

biolint reports:

```text
warning[SAM019]: `DT:23/06/2020` is not an ISO 8601 date
 --> example.sam:3:26
  |
3 | @RG→ID:rg1→SM:sample1→DT:23/06/2020
  |                          ^^^^^^^^^^
  = help: write the run date as `YYYY-MM-DD` or `YYYY-MM-DDThh:mm:ss+hh:mm`
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→M5:7fc56270e7a70fa81a5935b72eacbe29→TP:linear
@RG→ID:rg1→SM:sample1→DT:2020-06-23T12:13:47+01:00→PI:350
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:rg1
```

## Configuration

Silence it with `--ignore SAM019`, or check only this rule with `--select SAM019`.
