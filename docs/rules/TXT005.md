# TXT005: Carriage return inside a line

| | |
|---|---|
| Name | `bare-cr` |
| Format | Any format |
| Level | `error` |

A carriage return that is not followed by a line feed. Files with classic Mac OS line endings (CR only) look like one enormous line to every modern tool. Convert with `mac2unix` or `tr '\r' '\n'`.

## Example

```text
>seq1␍ACGT
```

biolint reports:

```text
error[TXT005]: carriage return in the middle of a line
 --> example.fasta:1:6
  |
1 | >seq1␦ACGT
  |      ^
  = help: if the whole file is one line, it has classic Mac line endings: convert with `mac2unix` or `tr '\r' '\n'`
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore TXT005`, or check only this rule with `--select TXT005`.
