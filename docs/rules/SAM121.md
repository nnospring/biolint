# SAM121: QUAL contains a character outside the Phred+33 range

| | |
|---|---|
| Name | `qual-invalid` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

Each quality is one printable character from `!` (0) to `~` (93): the Phred score plus 33. A space or a non-ASCII byte is not a quality; samtools stops with "invalid QUAL character".

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→II II
```

biolint reports:

```text
error[SAM121]: QUAL contains a space
 --> example.sam:3:34
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→II II
  |                                  ^
  = help: qualities are the characters `!` to `~` (Phred+33); a space usually means two columns were joined or the line was edited by hand
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM121`, or check only this rule with `--select SAM121`.
