# SAM016: @RG PL is not a platform the specification lists

| | |
|---|---|
| Name | `rg-platform-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

`PL` comes from a fixed list, in upper case: `CAPILLARY`, `DNBSEQ`, `ELEMENT`, `HELICOS`, `ILLUMINA`, `IONTORRENT`, `LS454`, `ONT`, `PACBIO`, `SINGULAR`, `SOLID` and `ULTIMA`. samtools does not check the value; a tool that chooses its behaviour by platform can only recognise the listed names. For any other technology, leave `PL` out and describe the instrument in `PM`.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@RG→ID:rg1→SM:sample1→PL:Nanopore
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:rg1
```

biolint reports:

```text
warning[SAM016]: `PL:Nanopore` is not a platform name
 --> example.sam:3:26
  |
3 | @RG→ID:rg1→SM:sample1→PL:Nanopore
  |                          ^^^^^^^^
  = help: did you mean `PL:ONT`? put the instrument model in `PM`
  = spec: SAM v1 §1.3
```

The name for 454 instruments is LS454:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@RG→ID:rg1→SM:sample1→PL:454
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:rg1
```

biolint reports:

```text
warning[SAM016]: `PL:454` is not a platform name
 --> example.sam:3:26
  |
3 | @RG→ID:rg1→SM:sample1→PL:454
  |                          ^^^
  = help: did you mean `PL:LS454`? put the instrument model in `PM`
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM016`, or check only this rule with `--select SAM016`.
