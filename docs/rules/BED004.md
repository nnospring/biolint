# BED004: Column header line is not commented out

| | |
|---|---|
| Name | `header-line` |
| Format | BED |
| Level | `warning` by default, `error` with `--strict` |
| Source | BED v1.0 §1.4 |

BED has no column header. A first line such as `chrom start end` is read as a feature whose start is the word "start", so parsers stop there or carry a bogus feature along; a few tools skip some header spellings, which hides the problem until another tool is used. Spreadsheets and `write.table(..., col.names = TRUE)` add such a line. Delete it, or turn it into a comment by starting it with `#`.

## Example

```text
chrom→start→end→name
chr1→1000→5000→geneA
```

biolint reports:

```text
warning[BED004]: the first line is a column header (`start`, `end`), not a feature
 --> example.bed:1:1
  |
1 | chrom→start→end→name
  | ^^^^^^^^^^^^^^^^^^^^
  = help: delete the line, or start it with `#` to make it a comment
  = fix: Comment out the header line (--fix)
  = spec: BED v1.0 §1.4
```

In these listings `→` stands for a tab.

## Accepted

```text
#chrom→start→end→name
chr1→1000→5000→geneA
```

## Configuration

Silence it with `--ignore BED004`, or check only this rule with `--select BED004`.
