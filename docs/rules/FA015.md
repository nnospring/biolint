# FA015: Sequence contains both T and U

| | |
|---|---|
| Name | `mixed-uracil-thymine` |
| Format | FASTA |
| Level | `warning` |
| Source | IUPAC-IUB (NC-IUB 1984) nucleotide codes |

A nucleotide sequence is written either as DNA (with `T`) or as RNA (with `U`). Both in one record usually means an RNA sequence was only partly converted, or two sources were pasted together. Tools that expect DNA do not all read `U` as `T`; where they do not, every `U` becomes a mismatch or an `N`. Convert with `seqkit seq --rna2dna` (or `--dna2rna`).

## Example

```text
>mir21 partly converted
UAGCUUAUCAGACTGATGTTGACTGUUGAAUCUCAUGG
```

biolint reports:

```text
warning[FA015]: `T` in a sequence that also contains `U`
 --> example.fasta:2:14
  |
2 | UAGCUUAUCAGACTGATGTTGACTGUUGAAUCUCAUGG
  |              ^
  = help: write the whole sequence as DNA (`seqkit seq --rna2dna`) or as RNA (`seqkit seq --dna2rna`)
  = spec: IUPAC-IUB (NC-IUB 1984) nucleotide codes
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA015`, or check only this rule with `--select FA015`.
