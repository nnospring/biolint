# GFF301: ID is used by two different features

| | |
|---|---|
| Name | `id-duplicate` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Column 9: "attributes" (ID) |

An ID must be unique in the file. The same ID may appear on several lines only when those lines are the pieces of one discontinuous feature, such as a CDS spread over several exons: they then have the same type and lie on the same sequence. An ID shared by a gene and its mRNA, or by features on different sequences, makes every `Parent` that refers to it ambiguous, and GenomeTools stops at the second use. Concatenated files and scripts that number features per chromosome are the usual sources.

## Example

A gene and an mRNA with the same ID:

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=abcA
chr1→example→mRNA→2100→7400→.→+→.→ID=abcA
```

biolint reports:

```text
error[GFF301]: ID `abcA` is already used by a `gene` feature
 --> example.gff3:3:38
  |
3 | chr1→example→mRNA→2100→7400→.→+→.→ID=abcA
  |                                      ^^^^
  = help: give this mRNA its own ID; lines may share an ID only when they are the parts of one feature
  = note: first used on line 2
  = spec: GFF3 1.26, Column 9: "attributes" (ID)
```

The same ID on two sequences:

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
chr2→example→gene→500→800→.→+→.→ID=gene1
```

biolint reports:

```text
error[GFF301]: ID `gene1` is already used by a feature on `chr1`
 --> example.gff3:3:36
  |
3 | chr2→example→gene→500→800→.→+→.→ID=gene1
  |                                    ^^^^^
  = help: IDs must be unique in the whole file, not per sequence: prefix them with the sequence name, or merge files with a tool that renames clashing IDs
  = note: first used on line 2
  = spec: GFF3 1.26, Column 9: "attributes" (ID)
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
##sequence-region chr1 1 50000
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Name=abcA
chr1→example→mRNA→2100→7400→.→+→.→ID=tx1;Parent=gene1
chr1→example→exon→2100→2600→.→+→.→Parent=tx1
chr1→example→exon→4000→7400→.→+→.→Parent=tx1
chr1→example→CDS→2300→2600→.→+→0→ID=cds1;Parent=tx1
chr1→example→CDS→4000→4701→.→+→2→ID=cds1;Parent=tx1
```

## Configuration

Silence it with `--ignore GFF301`, or check only this rule with `--select GFF301`.
