# VCF204: CHROM is not declared in a ##contig line

| | |
|---|---|
| Name | `chrom-undeclared` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.4.7 |

The header declares contigs, but not this one. BCF conversion and indexing need every contig declared, and a mismatch such as `chr1` vs `1` between header and records is a frequent source of "empty" query results. Reported once per contig name.

## Example

```text
##fileformat=VCFv4.3
##contig=<ID=chr1,length=248956422>
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
warning[VCF204]: contig `1` is not declared in any `##contig` line
 --> example.vcf:4:1
  |
4 | 1→100→.→A→T→.→.→.
  | ^
  = help: the header declares `chr1`: header and records use different naming (`chr` prefix); rename with `bcftools annotate --rename-chrs`
  = spec: VCF 4.3 §1.4.7
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF204`, or check only this rule with `--select VCF204`.
