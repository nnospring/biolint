# BED035: Strand is not `+`, `-` or `.`

| | |
|---|---|
| Name | `strand-invalid` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.7 |

The strand is a single character: `+`, `-`, or `.` when it is unknown or does not apply. Words (`plus`, `forward`), numbers (`1`, `-1`) and the `*` used by Bioconductor are not understood: strand-aware operations then treat the feature as unstranded, drop it, or stop.

## Example

```text
chr1→1000→5000→geneA→0→+
chr1→7000→7250→geneB→0→minus
```

biolint reports:

```text
error[BED035]: strand `minus` is not `+`, `-` or `.`
 --> example.bed:2:24
  |
2 | chr1→7000→7250→geneB→0→minus
  |                        ^^^^^
  = help: write `-`
  = note: 6 fields per line, all read as standard fields (BED6, inferred from line 1); if column 6 is a custom field instead, declare it with `--option bed.type=bed5+1`
  = spec: BED v1.0 §1.7
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED035`, or check only this rule with `--select BED035`.
