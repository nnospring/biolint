# VCF311: Reserved INFO key has an impossible value

| | |
|---|---|
| Name | `reserved-value` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.6.1 |

Beyond their type, reserved keys have meanings that bound their values: counts (`AC`, `AN`, `DP`, `NS`, `MQ0`) and `END` cannot be negative, `AF` is a fraction between 0 and 1, `CIGAR` is a CIGAR string.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=AF,Number=A,Type=Float,Description="Allele frequency">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→AF=12.5
```

biolint reports:

```text
warning[VCF311]: allele frequency 12.5 is outside 0–1
 --> example.vcf:4:20
  |
4 | 1→100→.→A→T→.→.→AF=12.5
  |                    ^^^^
  = help: AF is a fraction between 0 and 1 (not a percentage)
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF311`, or check only this rule with `--select VCF311`.
