# GFF211: Space before an attribute tag

| | |
|---|---|
| Name | `attribute-whitespace` |
| Format | GFF3 |
| Level | `warning` |
| Source | GFF3 1.26, Column 9: "attributes" |

Attributes are separated by a semicolon alone. With `ID=gene1; Parent=x` the second tag is ` Parent`, with a leading space, and parsers that compare tags exactly do not recognise it as `Parent`. The space comes from files written in the GTF habit of `; ` separators.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1; Name=abcA
```

biolint reports:

```text
warning[GFF211]: space before the tag `Name`
 --> example.gff3:2:44
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1; Name=abcA
  |                                            ^
  = help: separate attributes with `;` alone: parsers that keep the space do not recognise the tag
  = spec: GFF3 1.26, Column 9: "attributes"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF211`, or check only this rule with `--select GFF211`.
