# SAM124: CIGAR uses the obsolete B operation

| | |
|---|---|
| Name | `cigar-back-operation` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.4 |

`B` ("back": move backwards along the reference) is not among the operations the specification lists (`M I D N S H P = X`). samtools still reads and writes it, so the file passes there, but a tool written from the specification has no meaning for it. biolint does not compare such a CIGAR with SEQ.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→3M1B3M→*→0→0→ACGTAC→IIIIII
```

biolint reports:

```text
warning[SAM124]: CIGAR `3M1B3M` uses the obsolete `B` (back) operation
 --> example.sam:3:19
  |
3 | r1→0→chr1→10→30→3M1B3M→*→0→0→ACGTAC→IIIIII
  |                   ^^
  = help: rewrite the alignment without `B`: describe overlapping segments as separate records (the second one flagged supplementary)
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM124`, or check only this rule with `--select SAM124`.
