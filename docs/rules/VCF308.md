# VCF308: Whitespace in INFO

| | |
|---|---|
| Name | `info-whitespace` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.2 §1.4.1 |

Before VCF 4.3, INFO may not contain whitespace at all; from 4.3 spaces are allowed inside values but not around keys. Older parsers (and anything that splits on whitespace) truncate the record at the space.

## Example

```text
##fileformat=VCFv4.2
##INFO=<ID=GENE,Number=1,Type=String,Description="Gene name">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→GENE=BRCA 1
```

biolint reports:

```text
warning[VCF308]: INFO contains a space, which VCF 4.2 does not allow
 --> example.vcf:4:26
  |
4 | 1→100→.→A→T→.→.→GENE=BRCA 1
  |                          ^
  = help: replace spaces (commonly with `_`), or declare `##fileformat=VCFv4.3`, which allows spaces inside values
  = spec: VCF 4.2 §1.4.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF308`, or check only this rule with `--select VCF308`.
