# VCF005: Structured meta line is not well-formed

| | |
|---|---|
| Name | `meta-structure` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4 |

A structured line is `##key=<k=v,k=v,...>`: it must close with `>`, every entry needs a key and `=`, and a quoted value must end with an unescaped `"`. The usual culprit is a Description containing a `"` that was not escaped as `\"`, or a missing closing quote.

## Example

The Description never closes its quote:

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth>
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
error[VCF005]: quoted value of `Description` is never closed
 --> example.vcf:2:49
  |
2 | ##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth>
  |                                                 ^
  = help: add the closing `"` before `>`; a `"` inside the text must be written `\"`
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF005`, or check only this rule with `--select VCF005`.
