# TXT013: Blank lines at the end of the file

| | |
|---|---|
| Name | `trailing-blank-lines` |
| Format | Any format |
| Level | `warning` |
| Fixable | yes, with `biolint --fix` |

The file ends with one or more empty lines. Most parsers ignore them, but some treat an empty line as a malformed record, and line counts (`wc -l`) no longer equal record counts.

## Example

```text
>seq1
ACGT
```

biolint reports:

```text
warning[TXT013]: 2 blank lines at the end of the file
 --> example.fasta:3
  = help: delete the empty lines
  = fix: Remove trailing blank lines (--fix)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore TXT013`, or check only this rule with `--select TXT013`.
