# VCF019: Number value is newer than the declared VCF version

| | |
|---|---|
| Name | `meta-number-version` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.2 §1.2.2 |

`Number=R` exists from VCF 4.2. A 4.1 header using it is accepted by htslib but rejected by parsers that follow the declared version.

## Example

```text
##fileformat=VCFv4.1
##INFO=<ID=AD,Number=R,Type=Integer,Description="Allelic depths">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→AD=3,4
```

biolint reports:

```text
warning[VCF019]: `Number=R` was introduced in VCF 4.2 but this file declares VCF 4.1
 --> example.vcf:2:22
  |
2 | ##INFO=<ID=AD,Number=R,Type=Integer,Description="Allelic depths">
  |                      ^
  = help: change the first line to `##fileformat=VCFv4.2`
  = spec: VCF 4.2 §1.2.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF019`, or check only this rule with `--select VCF019`.
