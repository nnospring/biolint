# VCF106: Comment line among the records

| | |
|---|---|
| Name | `comment-in-body` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.4, §1.6 |

After the `#CHROM` line every line is a data record: VCF has no comment syntax there. Such lines do occur in the wild (`#FGQB` lines in some gVCF files, for example), and a reader is free to skip them or to fail on them.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
# checked by hand
1→200→.→G→C→.→.→.
```

biolint reports:

```text
warning[VCF106]: line starting with `#` among the records
 --> example.vcf:4:1
  |
4 | # checked by hand
  | ^^^^^^^^^^^^^^^^^
  = help: VCF has no comment syntax after the header: remove the line, or move the information into a `##` meta line above `#CHROM`
  = spec: VCF 4.3 §1.4, §1.6
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF106`, or check only this rule with `--select VCF106`.
