# BED021: Chromosome names mix the `chr1` and `1` styles

| | |
|---|---|
| Name | `chrom-naming-mixed` |
| Format | BED |
| Level | `warning` |
| Source | BED v1.0 §3.1 |

UCSC names chromosomes `chr1`, `chrX`, `chrM`; Ensembl and NCBI use `1`, `X`, `MT`. Tools compare names as plain text, so `chr1` and `1` are two different sequences and features on one of them are silently ignored in any comparison. A file that contains both styles is usually two files from different sources joined together.

## Example

```text
chr1→1000→5000
1→7000→7250
```

biolint reports:

```text
warning[BED021]: chrom `1` is written without `chr`, but line 1 uses the other style
 --> example.bed:2:1
  |
2 | 1→7000→7250
  | ^
  = help: tools treat `chr1` and `1` as different sequences; use the naming of your reference genome throughout (`sed 's/^chr//'` removes the prefix, `sed '/^[^#]/s/^/chr/'` adds it)
  = note: first name in the other style is on line 1
  = spec: BED v1.0 §3.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED021`, or check only this rule with `--select BED021`.
