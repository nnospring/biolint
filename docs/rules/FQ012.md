# FQ012: Blank line between records

| | |
|---|---|
| Name | `blank-line` |
| Format | FASTQ |
| Level | `error` |
| Source | Cock et al. 2010 (NAR 38:1767), "FASTQ definition" |

An empty line appears where a title line was expected, with more records after it. The format has no blank lines between records, and strict four-line parsers stop there, while kseq-based readers (bwa, minimap2, seqtk) skip ahead to the next `@`. Remove the empty lines, taking care not to delete the empty sequence and quality lines of zero-length reads.

## Example

```text
@read1
ACGTACGT
+
IIIIIIII

@read2
ACGTACGT
+
IIIIIIII
```

biolint reports:

```text
error[FQ012]: 1 blank line between records
 --> example.fastq:5
  = help: remove the empty line; four-line parsers stop here
  = spec: Cock et al. 2010 (NAR 38:1767), "FASTQ definition"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FQ012`, or check only this rule with `--select FQ012`.
