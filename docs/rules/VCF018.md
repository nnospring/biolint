# VCF018: Meta key differs from a standard key only by case

| | |
|---|---|
| Name | `meta-key-case` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.4 |

Meta keys are case-sensitive: `##Info=` or `##format=` is an unrelated custom line, so the definitions it was meant to provide are silently missing.

## Example

```text
##fileformat=VCFv4.3
##info=<ID=DP,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
warning[VCF018]: `##info` is not the standard key `##INFO`: meta keys are case-sensitive
 --> example.vcf:2:3
  |
2 | ##info=<ID=DP,Number=1,Type=Integer,Description="Total depth">
  |   ^^^^
  = help: write `##INFO=`
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF018`, or check only this rule with `--select VCF018`.
