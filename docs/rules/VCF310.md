# VCF310: Integer does not fit in 32 bits

| | |
|---|---|
| Name | `integer-range` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.3 |

Integers are 32-bit signed, and the eight smallest values (−2³¹ to −2³¹+7) are reserved by BCF for missing/end-of-vector markers. Larger magnitudes overflow when the file is converted to BCF.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3000000000
```

biolint reports:

```text
error[VCF310]: `DP` value 3000000000 does not fit in a 32-bit signed integer
 --> example.vcf:4:20
  |
4 | 1→100→.→A→T→.→.→DP=3000000000
  |                    ^^^^^^^^^^
  = help: the valid range is −2147483640 to 2147483647; declare the key as `Type=Float` or `Type=String` if it needs larger values
  = spec: VCF 4.3 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF310`, or check only this rule with `--select VCF310`.
