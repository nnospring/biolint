# VCF104: Duplicate sample name

| | |
|---|---|
| Name | `header-duplicate-sample` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.5 |

Sample names must be unique. htslib refuses to open a VCF with duplicate sample columns ("Duplicated sample name"). Rename with `bcftools reheader -s`.

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1→S1
1→100→.→A→T→.→.→.→GT→0/1→0/0
```

biolint reports:

```text
error[VCF104]: sample name `S1` appears twice (columns 10 and 11)
 --> example.vcf:3:50
  |
3 | #CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1→S1
  |                                                  ^^
  = help: give every sample a unique name, e.g. with `bcftools reheader -s`
  = spec: VCF 4.3 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF104`, or check only this rule with `--select VCF104`.
