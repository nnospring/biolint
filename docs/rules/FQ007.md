# FQ007: Record is incomplete

| | |
|---|---|
| Name | `truncated-record` |
| Format | FASTQ |
| Level | `error` |
| Source | Cock et al. 2010 (NAR 38:1767), "FASTQ definition" |

A record needs four parts: title, sequence, `+` line and quality. Here the file ends, or the next record begins, before all four were seen. At the end of a file this is the signature of truncation: an interrupted download or copy, a job killed while writing, or `head -n` with a count that is not a multiple of four. Regenerate or re-transfer the file and compare checksums.

## Example

The file ends after the sequence of the last record:

```text
@read1
ACGTACGT
+
IIIIIIII
@read2
ACGTACGT
```

biolint reports:

```text
error[FQ007]: the file ends inside read `read2`: the `+` and quality lines are missing
 --> example.fastq:5
  = help: the file is truncated (interrupted transfer, full disk, `head -n` with a count that is not a multiple of 4): fetch or generate it again and compare checksums
  = spec: Cock et al. 2010 (NAR 38:1767), "FASTQ definition"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FQ007`, or check only this rule with `--select FQ007`.
