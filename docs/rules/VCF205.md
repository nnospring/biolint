# VCF205: Invalid POS

| | |
|---|---|
| Name | `pos-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

POS is a non-negative integer (1-based; 0 is reserved for telomeres) that fits in 32 bits. Decimal points, thousands separators and scientific notation (`1e+05`, a spreadsheet artefact) are invalid.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→1e+05→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF205]: POS `1e+05` is not a valid position
 --> example.vcf:3:3
  |
3 | 1→1e+05→.→A→T→.→.→.
  |   ^^^^^
  = help: scientific notation is usually a spreadsheet artefact; write the integer, e.g. `100000`
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF205`, or check only this rule with `--select VCF205`.
