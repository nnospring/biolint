# VCF407: Sample value does not match the declared Type

| | |
|---|---|
| Name | `sample-type` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.3 |

As for INFO: Integer, Float and Character values must parse as such. `NA`, an empty string or a decimal in an Integer field are the usual causes.

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=DP,Number=1,Type=Integer,Description="Read depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT:DP→0/1:NA
```

biolint reports:

```text
error[VCF407]: `DP` is declared as Integer but has the value `NA`
 --> example.vcf:5:29
  |
5 | 1→100→.→A→T→.→.→.→GT:DP→0/1:NA
  |                             ^^
  = help: write `.` for a missing value
  = note: declared on line 3
  = spec: VCF 4.3 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF407`, or check only this rule with `--select VCF407`.
