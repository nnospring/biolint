# TXT012: Line is too long to check

| | |
|---|---|
| Name | `line-too-long` |
| Format | Any format |
| Level | `error` |

A single line exceeds the size biolint is willing to hold in memory for this format. In tab-separated formats this almost always means missing line breaks.

## Configuration

Silence it with `--ignore TXT012`, or check only this rule with `--select TXT012`.
