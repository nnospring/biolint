# VCF303: Duplicate INFO key

| | |
|---|---|
| Name | `info-duplicate-key` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

A key may appear once per record. Which value survives a duplicate differs between tools, so annotations silently disagree. Usually produced by annotating the same file twice.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3;DP=5
```

biolint reports:

```text
error[VCF303]: INFO key `DP` appears twice in this record
 --> example.vcf:4:22
  |
4 | 1→100→.→A→T→.→.→DP=3;DP=5
  |                      ^^
  = help: keep one of the two entries
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF303`, or check only this rule with `--select VCF303`.
