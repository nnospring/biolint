# SAM209: RG tag names a read group the header does not define

| | |
|---|---|
| Name | `rg-undeclared` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAMtags §1.2 |

When the header has `@RG` lines, the value of every `RG:Z:` tag must be the `ID` of one of them. Reads with an unknown read group have no sample or library. The header was probably replaced (`samtools reheader`) or the files were merged without their read groups.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@RG→ID:lane1→SM:sampleA
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:lane2
```

biolint reports:

```text
warning[SAM209]: read group `lane2` is not defined by any @RG line
 --> example.sam:4:43
  |
4 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→RG:Z:lane2
  |                                           ^^^^^
  = help: did you mean `RG:Z:lane1`? otherwise add `@RG<tab>ID:lane2` to the header
  = spec: SAMtags §1.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM209`, or check only this rule with `--select SAM209`.
