# SAM101: Alignment line has fewer than 11 tab-separated fields

| | |
|---|---|
| Name | `too-few-fields` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

Every alignment line has eleven mandatory fields separated by single tabs: QNAME, FLAG, RNAME, POS, MAPQ, CIGAR, RNEXT, PNEXT, TLEN, SEQ and QUAL. A field with nothing to say holds `*` or `0`; it is never left out. Short lines come from tabs turned into spaces, or from a file cut off while it was being written.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA
```

biolint reports:

```text
error[SAM101]: alignment line has 10 tab-separated fields; 11 are required
 --> example.sam:3:1
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: one field is missing; QUAL is the usual one: write `*` when base qualities are not stored
  = spec: SAM v1 §1.4
```

Spaces instead of tabs:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1 0 chr1 10 30 5M * 0 0 ACGTA IIIII
```

biolint reports:

```text
error[SAM101]: alignment line has 1 tab-separated field; 11 are required
 --> example.sam:3:1
  |
3 | r1 0 chr1 10 30 5M * 0 0 ACGTA IIIII
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: the columns are separated by spaces: SAM fields must be separated by single tab characters (an editor or a copy from a terminal may have converted them)
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

```text
@HD→VN:1.6→SO:coordinate
@SQ→SN:chr1→LN:248956422
@RG→ID:rg1→SM:sample1→PL:ILLUMINA
@PG→ID:bwa→PN:bwa→VN:0.7.17
read1→99→chr1→100→60→10M→=→200→110→ACGTACGTAC→IIIIIIIIII→NM:i:0→RG:Z:rg1
read1→147→chr1→200→60→10M→=→100→-110→ACGTACGTAC→IIIIIIIIII→NM:i:0→RG:Z:rg1
```

## Configuration

Silence it with `--ignore SAM101`, or check only this rule with `--select SAM101`.
