# BED007: Line ends with a space or tab

| | |
|---|---|
| Name | `trailing-whitespace` |
| Format | BED |
| Level | `warning` |

A tab at the end of a line adds an empty last field, and a trailing space becomes part of the last value (`+ ` is not a strand). Spreadsheet exports and hand editing leave these behind. Some parsers ignore them and others count an extra column, so the same file behaves differently from tool to tool.

## Example

```text
chr1→1000→5000→geneA
chr1→7000→7250→geneB→
```

biolint reports:

```text
warning[BED007]: line ends with a tab
 --> example.bed:2:21
  |
2 | chr1→7000→7250→geneB→
  |                     ^
  = help: delete it; a trailing tab adds an empty last column in tools that split on tabs
  = fix: Remove the trailing whitespace (--fix)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED007`, or check only this rule with `--select BED007`.
