# SAM205: Optional field value does not fit its type

| | |
|---|---|
| Name | `aux-value-invalid` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.5 |

The value must fit the declared type: `A` is exactly one character; `i` is an integer from -2^31 to 2^32-1; `f` is a number; `H` is an even number of hexadecimal digits; `B` is an element type (`c C s S i I f`) followed by comma-separated numbers. samtools stops on some of these and silently changes others: `XI:i:1.5` is read as 1, `XI:i:abc` as 0, `XA:A:ab` as `a`, and an empty array element as 0.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:1.5
```

biolint reports:

```text
error[SAM205]: `1.5` is not an integer (`NM` has type `i`)
 --> example.sam:3:43
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:i:1.5
  |                                           ^^^
  = help: this is not a whole number (samtools reads it as 1): use type `f`, `NM:f:1.5`, or round the value
  = spec: SAM v1 §1.5
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→XB:B:i,1,,3
```

biolint reports:

```text
error[SAM205]: array value of `XB` has an empty element
 --> example.sam:3:46
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→XB:B:i,1,,3
  |                                              ^^
  = help: remove the extra comma; samtools reads an empty element as 0
  = spec: SAM v1 §1.5
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→XH:H:ABC
```

biolint reports:

```text
error[SAM205]: hex value of `XH` has 3 digits; a byte array needs an even number
 --> example.sam:3:43
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→XH:H:ABC
  |                                           ^^^
  = help: each byte is two digits: a digit is missing, or the value should start with 0 (`0ABC`)
  = spec: SAM v1 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM205`, or check only this rule with `--select SAM205`.
