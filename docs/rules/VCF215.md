# VCF215: Invalid QUAL

| | |
|---|---|
| Name | `qual-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

QUAL is a number or `.`. Text such as `NA`, `PASS` (a shifted column) or a decimal comma is invalid.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→NA→.→.
```

biolint reports:

```text
error[VCF215]: QUAL `NA` is not a number
 --> example.vcf:3:13
  |
3 | 1→100→.→A→T→NA→.→.
  |             ^^
  = help: write a number, or `.` if unknown
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF215`, or check only this rule with `--select VCF215`.
