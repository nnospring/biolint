# TXT006: Invalid UTF-8 byte sequence

| | |
|---|---|
| Name | `invalid-utf8` |
| Format | Any format |
| Level | `error` |

The bytes are not valid UTF-8. The file was probably written in a legacy encoding (Latin-1, Windows-1252, GBK, Shift-JIS) or was truncated in the middle of a character. Re-encode with `iconv -f <encoding> -t UTF-8`.

## Configuration

Silence it with `--ignore TXT006`, or check only this rule with `--select TXT006`.
