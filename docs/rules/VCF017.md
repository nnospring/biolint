# VCF017: Contig length is not a positive integer

| | |
|---|---|
| Name | `contig-length-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4.7 |

The `length` of a `##contig` line must be a positive integer. tabix and `bcftools index` use it to size the index; units, decimals and separators break that.

## Example

```text
##fileformat=VCFv4.3
##contig=<ID=1,length=248.9Mb>
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF017]: contig length `248.9Mb` is not a positive integer
 --> example.vcf:2:23
  |
2 | ##contig=<ID=1,length=248.9Mb>
  |                       ^^^^^^^
  = help: use the sequence length in bases, digits only
  = spec: VCF 4.3 §1.4.7
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF017`, or check only this rule with `--select VCF017`.
