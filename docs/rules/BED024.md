# BED024: Coordinate does not fit in 32 bits

| | |
|---|---|
| Name | `coordinate-too-large` |
| Format | BED |
| Level | `warning` |
| Source | BED v1.0 §1.6 |

The specification allows coordinates up to 2^64−1 when the chromosome length is unknown, but a coordinate must never exceed the length of its chromosome, and only a handful of sequenced chromosomes are longer than 4,294,967,295 bases. Much software stores positions in 32-bit integers and overflows beyond that. A value this large is almost always an arithmetic overflow or a corrupted number.

## Example

```text
chr1→4294967196→4294967296
```

biolint reports:

```text
warning[BED024]: chromEnd `4294967296` is larger than 4,294,967,295
 --> example.bed:1:17
  |
1 | chr1→4294967196→4294967296
  |                 ^^^^^^^^^^
  = help: check where this number comes from: it is beyond the length of almost every known chromosome and beyond what 32-bit tools (UCSC utilities, bedtools, bigBed) can store
  = spec: BED v1.0 §1.6
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED024`, or check only this rule with `--select BED024`.
