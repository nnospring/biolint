# SAM103: Read name contains a character that is not allowed

| | |
|---|---|
| Name | `qname-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.2.1 |

A read name (QNAME) is 1 to 254 printable ASCII characters without spaces and without `@`, so that alignment lines can never be mistaken for header lines. A leading `@` is left over from a FASTQ header; a space means the FASTQ comment was not removed. samtools keeps such names, but a name starting with `@` on the first alignment line is read as a header line.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
@read2→0→chr1→20→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM103]: read name `@read2` starts with `@`
 --> example.sam:4:1
  |
4 | @read2→0→chr1→20→30→5M→*→0→0→ACGTA→IIIII
  | ^
  = help: remove the `@` (it is the FASTQ record marker, not part of the name); at the top of a file such a line is taken for a header line
  = spec: SAM v1 §1.2.1
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
read1 1:N:0:ACGT→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM103]: read name `read1 1:N:0:ACGT` contains a space
 --> example.sam:3:6
  |
3 | read1 1:N:0:ACGT→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
  |      ^
  = help: use the part before the space (`read1`): the rest is the FASTQ comment, which belongs in a `CO:Z:` or `BC:Z:` tag (bwa mem -C does this)
  = spec: SAM v1 §1.2.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM103`, or check only this rule with `--select SAM103`.
