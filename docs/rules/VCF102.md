# VCF102: Column header does not name the eight fixed columns

| | |
|---|---|
| Name | `header-columns` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.5 |

The header must be exactly `#CHROM`, `POS`, `ID`, `REF`, `ALT`, `QUAL`, `FILTER`, `INFO`, tab-separated, optionally followed by `FORMAT` and sample names. Spaces instead of tabs are the most common cause: they appear when a header is pasted from a terminal, an email or a document.

## Example

Columns separated by spaces instead of tabs:

```text
##fileformat=VCFv4.3
#CHROM POS ID REF ALT QUAL FILTER INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF102]: the column header is separated by spaces, not tabs
 --> example.vcf:2:1
  |
2 | #CHROM POS ID REF ALT QUAL FILTER INFO
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: replace the runs of spaces with single tab characters (and do the same in the records if needed)
  = spec: VCF 4.3 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF102`, or check only this rule with `--select VCF102`.
