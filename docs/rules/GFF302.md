# GFF302: Feature appears twice with the same ID and location

| | |
|---|---|
| Name | `id-repeated-same-location` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Column 9: "attributes" (ID) |

Lines that share an ID are the parts of one feature at several locations. Two lines with the same ID, type and coordinates are not two parts: the feature has been written twice, typically because a file was concatenated with itself or a merge did not remove duplicates.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
warning[GFF302]: ID `gene1` is repeated with the same type and location
 --> example.gff3:3:38
  |
3 | chr1→example→gene→2100→7400→.→+→.→ID=gene1
  |                                      ^^^^^
  = help: the feature is written twice: delete one of the lines (was the file concatenated with itself?)
  = note: first on line 2
  = spec: GFF3 1.26, Column 9: "attributes" (ID)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF302`, or check only this rule with `--select GFF302`.
