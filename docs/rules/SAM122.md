# SAM122: Integer field has a plus sign or leading zeros

| | |
|---|---|
| Name | `integer-format` |
| Format | SAM |
| Level | `warning` |
| Source | SAM v1 §1.4 |

POS, MAPQ, PNEXT and TLEN are integers. The specification gives their range but not their spelling, and samtools reads `+200` and `007` as 200 and 7. Another parser may not: samtools itself reads a leading zero in FLAG as octal. Write the plain decimal number.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→010→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM122]: POS `010` is written with leading zeros
 --> example.sam:3:11
  |
3 | r1→0→chr1→010→30→5M→*→0→0→ACGTA→IIIII
  |           ^^^
  = help: write `10`
  = spec: SAM v1 §1.4
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→+200→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM122]: TLEN `+200` is written with a plus sign
 --> example.sam:3:24
  |
3 | r1→0→chr1→10→30→5M→*→0→+200→ACGTA→IIIII
  |                        ^^^^
  = help: write `200`
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM122`, or check only this rule with `--select SAM122`.
