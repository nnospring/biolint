# VCF404: Sample has more fields than FORMAT has keys

| | |
|---|---|
| Name | `sample-field-count` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.2 |

A sample column may drop trailing fields but can never have more colon-separated fields than FORMAT lists. Extra fields mean a `:` inside a value or a FORMAT column that lost a key.

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT→0/1:12
```

biolint reports:

```text
error[VCF404]: sample has 2 fields but FORMAT lists 1 (`GT`)
 --> example.vcf:4:25
  |
4 | 1→100→.→A→T→.→.→.→GT→0/1:12
  |                         ^^^
  = help: a value may contain a `:`, or FORMAT is missing a key
  = spec: VCF 4.3 §1.6.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF404`, or check only this rule with `--select VCF404`.
