# FA006: Blank line between records

| | |
|---|---|
| Name | `blank-line-between-records` |
| Format | FASTA |
| Level | `info` by default, `warning` with `--strict` |
| Source | NCBI BLAST help, FASTA ("Blank lines are not allowed in the middle of FASTA input") |

There is an empty line before a `>` header. `samtools faidx` and most parsers skip it, so the file works; NCBI's description of the format does not allow it, and simple line-counting scripts miscount records. Remove the blank lines with `sed -i '/^$/d' file.fa`.

## Example

```text
>seq1
ACGTACGT

>seq2
ACGTACGT
```

biolint reports:

```text
info[FA006]: 1 blank line before the next header
 --> example.fasta:3
  = help: remove empty lines with `sed -i '/^[[:space:]]*$/d' file.fa`
  = spec: NCBI BLAST help, FASTA ("Blank lines are not allowed in the middle of FASTA input")
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA006`, or check only this rule with `--select FA006`.
