# GTF111: gene_id and transcript_id are not the first two attributes

| | |
|---|---|
| Name | `mandatory-attributes-not-first` |
| Format | GTF |
| Level | `off` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

GTF 2.2 puts `gene_id` first and `transcript_id` second, before any other attribute. Parsers in current use look attributes up by name, and Ensembl files place `gene_version` between the two, so the order is checked only in the strict profile.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→exon_number 1; gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF111]: `gene_id` is attribute 2, not the first
 --> example.gtf:1:50
  |
1 | chr1→example→exon→1200→1350→.→+→.→exon_number 1; gene_id "g1"; transcript_id "g1.t1";
  |                                                  ^^^^^^^
  = help: put `gene_id` first and `transcript_id` second, before all other attributes
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF111`, or check only this rule with `--select GTF111`.
