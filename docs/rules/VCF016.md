# VCF016: Optional meta field value is not quoted

| | |
|---|---|
| Name | `meta-optional-unquoted` |
| Format | VCF |
| Level | `off` by default, `warning` with `--strict` |
| Source | VCF 4.3 §1.4 |

From VCF 4.3, values of optional fields in INFO/FORMAT/FILTER/ALT lines (`Source`, `Version`, and any custom ones) must be written as quoted strings, even when numeric. Parsers accept the unquoted form, so this is reported in strict mode only.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth",Version=3>
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
warning[VCF016]: value of optional field `Version` must be a quoted string
 --> example.vcf:2:71
  |
2 | ##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth",Version=3>
  |                                                                       ^
  = help: write `Version="3"`
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF016`, or check only this rule with `--select VCF016`.
