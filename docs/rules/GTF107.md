# GTF107: Attributes are not separated by exactly one space

| | |
|---|---|
| Name | `attribute-separator` |
| Format | GTF |
| Level | `off` by default, `warning` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

GTF 2.2 asks for exactly one space between the semicolon that ends an attribute and the next key. Parsers that honour quotes read files without the space (`gene_id "g1";transcript_id "t1";`) or with several all the same, so this is reported only in the strict profile.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id "g1";transcript_id "g1.t1";
```

biolint reports:

```text
warning[GTF107]: no space between the semicolon and the next attribute
 --> example.gtf:1:47
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id "g1";transcript_id "g1.t1";
  |                                               ^
  = help: separate attributes with a semicolon followed by exactly one space
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF107`, or check only this rule with `--select GTF107`.
