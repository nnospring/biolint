# GFF003: ##gff-version is not the first line

| | |
|---|---|
| Name | `version-not-first` |
| Format | GFF3 |
| Level | `off` by default, `error` with `--strict` |
| Source | GFF3 1.26, Other Syntax: ##gff-version |

The specification requires `##gff-version` to be the topmost line of the file. Comments, blank lines or other directives above it are tolerated by nearly every parser, so this is only reported in the strict profile.

## Example

```text
# exported 2024-05-01
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
error[GFF003]: `##gff-version` is on line 2, not on the first line
 --> example.gff3:2:1
  |
2 | ##gff-version 3
  | ^^^^^^^^^^^^^
  = help: move it to the very top of the file
  = spec: GFF3 1.26, Other Syntax: ##gff-version
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF003`, or check only this rule with `--select GFF003`.
