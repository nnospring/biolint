# VCF219: Contig name contains characters that are not allowed

| | |
|---|---|
| Name | `chrom-characters` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.4.7 |

Contig names follow the SAM rules (stated explicitly from VCF 4.3): printable ASCII except `\ , " ` ' ( ) [ ] { } < >`, not starting with `*` or `=`. Names outside this set collide with region syntax (`chr:start-end`), breakend notation or `##contig` parsing. Reported once per name.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
chr1,alt→100→.→A→T→.→.→.
```

biolint reports:

```text
warning[VCF219]: contig name `chr1,alt` contains `,`, which is not allowed in contig names
 --> example.vcf:3:5
  |
3 | chr1,alt→100→.→A→T→.→.→.
  |     ^
  = help: contig names follow the SAM rules: printable ASCII except \ , " ` ' ( ) [ ] { } < >, and not starting with `*` or `=`
  = spec: VCF 4.3 §1.4.7
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF219`, or check only this rule with `--select VCF219`.
