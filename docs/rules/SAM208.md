# SAM208: Predefined tag used with the wrong type

| | |
|---|---|
| Name | `aux-type-mismatch` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAMtags §1 |

Tags in upper case that do not start with X, Y or Z are defined by the specification, each with one type: `NM:i`, `MD:Z`, `RG:Z`, `AS:i`, `SA:Z`, `ML:B` and so on. A tool that expects the edit distance in `NM` as an integer cannot use `NM:Z:2`. For your own data use a lower-case tag or one starting with X, Y or Z.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:Z:2
```

biolint reports:

```text
warning[SAM208]: `NM` is a predefined tag of type `i` (an integer), not `Z`
 --> example.sam:3:41
  |
3 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→NM:Z:2
  |                                         ^
  = help: write it as `NM:i:...`, or use a tag of your own (lower case, or starting with X, Y or Z) for different data
  = spec: SAMtags §1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM208`, or check only this rule with `--select SAM208`.
