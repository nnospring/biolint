# VCF403: FORMAT key is not declared in the header

| | |
|---|---|
| Name | `format-undeclared` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.4.4 |

Each FORMAT key should have a `##FORMAT=<ID=...>` line. htslib assumes `Number=1,Type=String` and warns; BCF conversion fails. Reported once per key.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT→0/1
```

biolint reports:

```text
warning[VCF403]: FORMAT key `GT` has no `##FORMAT` line
 --> example.vcf:3:19
  |
3 | 1→100→.→A→T→.→.→.→GT→0/1
  |                   ^^
  = help: add `##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">` to the header
  = spec: VCF 4.3 §1.4.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF403`, or check only this rule with `--select VCF403`.
