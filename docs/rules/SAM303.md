# SAM303: Header without alignment records

| | |
|---|---|
| Name | `no-alignments` |
| Format | SAM |
| Level | `info` |

The file has header lines and nothing else. That is a valid SAM file (it is what `samtools view -H` prints), but if reads were expected, the aligner produced none or the file was cut off after the header.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
```

biolint reports:

```text
info[SAM303]: the file has a header but no alignment records
 --> example.sam
  = help: fine for a header-only file; otherwise check that the aligner finished and wrote its output
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM303`, or check only this rule with `--select SAM303`.
