# VCF213: Symbolic ALT allele is not declared

| | |
|---|---|
| Name | `alt-undeclared` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.4.5 |

A symbolic allele such as `<DEL>` should have a matching `##ALT=<ID=DEL,...>` line. `<*>` and `<NON_REF>` (gVCF) need none. Reported once per allele.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→<DEL>→.→.→.
```

biolint reports:

```text
warning[VCF213]: symbolic allele `<DEL>` has no `##ALT=<ID=DEL,...>` line
 --> example.vcf:3:11
  |
3 | 1→100→.→A→<DEL>→.→.→.
  |           ^^^^^
  = help: add `##ALT=<ID=DEL,Description="...">` to the header
  = spec: VCF 4.3 §1.4.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF213`, or check only this rule with `--select VCF213`.
