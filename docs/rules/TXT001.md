# TXT001: File is UTF-16, not UTF-8

| | |
|---|---|
| Name | `utf16` |
| Format | Any format |
| Level | `error` |

The file starts with a UTF-16 byte-order mark or has a NUL in every other byte. Bioinformatics tools read bytes as ASCII/UTF-8 and will see garbage. This usually happens after saving from Windows Notepad ("Unicode"), PowerShell redirection (`>`), or Excel "Unicode Text".

## Configuration

Silence it with `--ignore TXT001`, or check only this rule with `--select TXT001`.
