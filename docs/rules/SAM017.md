# SAM017: Two @PG lines have the same ID

| | |
|---|---|
| Name | `pg-id-duplicate` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

Each `@PG` line needs its own `ID`, because `PP` tags and the `PG` tag of reads refer to it. Tools that append a step normally add a suffix (`bwa`, `bwa.1`); identical IDs come from pasting headers together.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@PG→ID:bwa→PN:bwa
@PG→ID:bwa→PN:bwa
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM017]: program ID `bwa` is already defined
 --> example.sam:4:8
  |
4 | @PG→ID:bwa→PN:bwa
  |        ^^^
  = help: give this step its own ID, e.g. `ID:bwa.1`
  = note: first defined on line 3
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM017`, or check only this rule with `--select SAM017`.
