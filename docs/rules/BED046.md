# BED046: Block extends beyond chromEnd

| | |
|---|---|
| Name | `block-outside-feature` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.9 |

Every block must lie inside the feature: chromStart + blockStart + blockSize may not exceed chromEnd. A block that sticks out usually means the starts are absolute coordinates rather than offsets from chromStart, or chromEnd was shortened without updating the blocks.

## Example

```text
chr22→1000→5000→cloneA→960→+→1000→5000→0→2→567,888→0,3512
```

biolint reports:

```text
error[BED046]: block 2 ends at offset `4400` (start `3512` + size `888`), beyond the feature length `4000`
 --> example.bed:1:54
  |
1 | chr22→1000→5000→cloneA→960→+→1000→5000→0→2→567,888→0,3512
  |                                                      ^^^^
  = help: block starts are offsets from chromStart, not chromosome positions: subtract `1000` from every entry
  = note: column 12 is read as blockStarts because the columns to its right on this line fit the standard fields that follow it; if column 12 is a custom field instead, declare it with `--option bed.type=bed9+3`
  = spec: BED v1.0 §1.9
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED046`, or check only this rule with `--select BED046`.
