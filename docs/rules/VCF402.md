# VCF402: GT is not the first FORMAT key

| | |
|---|---|
| Name | `gt-not-first` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.2 |

When genotypes are present, `GT` must be the first key. htslib and htsjdk both reject records where it is not.

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=DP,Number=1,Type=Integer,Description="Read depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→DP:GT→5:0/1
```

biolint reports:

```text
error[VCF402]: GT must be the first FORMAT key, but it is number 2
 --> example.vcf:5:22
  |
5 | 1→100→.→A→T→.→.→.→DP:GT→5:0/1
  |                      ^^
  = help: move GT (and the matching value in every sample) to the front
  = spec: VCF 4.3 §1.6.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF402`, or check only this rule with `--select VCF402`.
