# VCF208: POS is beyond the declared contig length

| | |
|---|---|
| Name | `pos-beyond-contig` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.6.1 |

POS exceeds `length + 1` of the contig declared in the header. The header and the records were probably produced against different reference builds.

## Example

```text
##fileformat=VCFv4.3
##contig=<ID=1,length=1000>
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→5000→.→A→T→.→.→.
```

biolint reports:

```text
warning[VCF208]: position 5000 is beyond the end of `1` (declared length 1000)
 --> example.vcf:4:3
  |
4 | 1→5000→.→A→T→.→.→.
  |   ^^^^
  = help: the header and the records probably refer to different reference builds
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF208`, or check only this rule with `--select VCF208`.
