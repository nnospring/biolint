# FQ002: The + separator line is missing

| | |
|---|---|
| Name | `plus-line-missing` |
| Format | FASTQ |
| Level | `error` |
| Source | Cock et al. 2010 (NAR 38:1767), "FASTQ definition" |

After the sequence comes a line starting with `+`, which separates the bases from their qualities. Without it a parser cannot tell where the sequence ends; it either stops or reads the quality string as more sequence. The line is usually lost when a file is truncated or edited by hand.

## Example

```text
@read1
ACGTACGT
IIIIIII!
@read2
ACGTACGT
+
IIIIIIII
```

biolint reports:

```text
error[FQ002]: expected the `+` line of read `read1` but found `IIIIIII!`
 --> example.fastq:3:1
  |
3 | IIIIIII!
  | ^
  = help: this line has the length of the sequence, so it is probably the quality string: insert a `+` line above it
  = note: record starts on line 1
  = spec: Cock et al. 2010 (NAR 38:1767), "FASTQ definition"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FQ002`, or check only this rule with `--select FQ002`.
