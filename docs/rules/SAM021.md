# SAM021: Blank line

| | |
|---|---|
| Name | `blank-line` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1 |

Every line of a SAM file is either a header line starting with `@` or an alignment with eleven fields; there are no empty lines. samtools reads a blank line as an alignment with no fields and stops with "Parse error", even when the blank line is the last line of the file. Editors and `echo` add them easily. Trailing blank lines are removed by `biolint --fix`.

## Example

Between two records:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII

r2→0→chr1→20→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM021]: blank line among the alignments
 --> example.sam:4
  = help: delete the empty line: samtools reads it as a malformed alignment and stops
  = spec: SAM v1 §1
```

At the end of the file:

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM021]: blank line at the end of the file
 --> example.sam:4
  = help: delete the empty line: samtools reads a blank line as a malformed alignment and stops
  = fix: Remove trailing blank lines (--fix)
  = spec: SAM v1 §1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM021`, or check only this rule with `--select SAM021`.
