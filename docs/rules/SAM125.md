# SAM125: RNAME or RNEXT uses an alternative name instead of the SN

| | |
|---|---|
| Name | `rname-is-alias` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

The names listed in `@SQ AN` let tools accept `chrM` when a user asks for `MT`, for example. They are not used inside the file: records must name a reference by its `SN`. samtools resolves the alias and writes the `SN` back, so the file changes on conversion; tools that look names up exactly do not find the reference.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:MT→LN:16569→AN:chrM
r1→0→chrM→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM125]: RNAME `chrM` is an alternative name (`AN`) of `MT`, not its `SN`
 --> example.sam:3:6
  |
3 | r1→0→chrM→10→30→5M→*→0→0→ACGTA→IIIII
  |      ^^^^
  = help: write `MT`: alternative names are for user queries and must not be used in records (samtools replaces it on reading)
  = note: @SQ line 2
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM125`, or check only this rule with `--select SAM125`.
