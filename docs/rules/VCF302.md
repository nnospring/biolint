# VCF302: Empty INFO entry (stray semicolon)

| | |
|---|---|
| Name | `info-empty-entry` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.6.1 |

A leading, trailing or doubled semicolon leaves an empty entry. htslib skips it, but stricter parsers (GATK/htsjdk, vcf-validator) reject the record.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3;
```

biolint reports:

```text
warning[VCF302]: INFO ends with a semicolon
 --> example.vcf:4:21
  |
4 | 1→100→.→A→T→.→.→DP=3;
  |                     ^
  = help: remove the extra semicolon
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF302`, or check only this rule with `--select VCF302`.
