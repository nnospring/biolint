# SAM117: TLEN is not an integer

| | |
|---|---|
| Name | `tlen-invalid` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

TLEN (observed template length) is a signed whole number, 0 when unknown. Decimals and `*` are parse errors in samtools.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→*→ACGTA→IIIII
```

biolint reports:

```text
error[SAM117]: TLEN `*` is not an integer
 --> example.sam:3:24
  |
3 | r1→0→chr1→10→30→5M→*→0→*→ACGTA→IIIII
  |                        ^
  = help: `*` is the placeholder of text fields; TLEN is a number and its placeholder is `0`
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM117`, or check only this rule with `--select SAM117`.
