# TXT003: Windows (CRLF) line endings

| | |
|---|---|
| Name | `crlf` |
| Format | Any format |
| Level | `warning` |
| Fixable | yes, with `biolint --fix` |

Lines end with carriage return + line feed. Most Unix tools keep the carriage return as part of the last field, which silently changes sample names, INFO values, sequence lengths and quality strings. Convert with `biolint --fix`, `dos2unix`, or `sed -i 's/\r$//'`.

## Example

```text
>seq1␍
ACGT␍
```

biolint reports:

```text
warning[TXT003]: line ends with a carriage return (Windows CRLF line ending)
 --> example.fasta:1:6
  |
1 | >seq1
  |      ^
  = help: convert to Unix line endings with `biolint --fix` or `dos2unix`
  = fix: Convert line endings to LF (--fix)

Not all occurrences are shown (use --max-per-rule 0 to see every one):
  TXT003  2 occurrences, 1 shown
```

In these listings `→` stands for a tab.

## Accepted

```text
>seq1
ACGT
```

## Configuration

Silence it with `--ignore TXT003`, or check only this rule with `--select TXT003`.
