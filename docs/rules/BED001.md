# BED001: File holds another format, not BED

| | |
|---|---|
| Name | `other-format` |
| Format | BED |
| Level | `error` |

The name says BED but the content is something else. The commonest case is a PLINK binary genotype file: PLINK also uses the `.bed` extension, for a binary matrix that has nothing to do with genome-browser BED. It also happens when a GFF, VCF, SAM or FASTA file is renamed by mistake. Nothing else is checked in such a file.

## Example

A GFF3 file saved with a .bed name:

```text
##gff-version 3
chr1→.→gene→1000→5000→.→+→.→ID=gene1
```

biolint reports:

```text
error[BED001]: the file starts with `##gff-version`: this is a GFF file, not BED
 --> example.bed:1:1
  |
1 | ##gff-version 3
  | ^^^^^^^^^^^^^^^
  = help: rename it to `.gff3`, or check it with `--type gff3`
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED001`, or check only this rule with `--select BED001`.
