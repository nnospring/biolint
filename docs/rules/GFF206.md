# GFF206: Attribute starting with an upper-case letter is not a defined tag

| | |
|---|---|
| Name | `reserved-tag-unknown` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Column 9: "attributes" |

Tags that begin with an upper-case letter are reserved for the specification, which defines `ID`, `Name`, `Alias`, `Parent`, `Target`, `Gap`, `Derives_from`, `Note`, `Dbxref`, `Ontology_term` and `Is_circular`. Your own attributes must start with a lower-case letter. Files in circulation carry such tags and tools generally pass them through, but GenomeTools rejects them, and a misspelt reserved tag (`PARENT`, `Id`, `DBxref`) is not recognised as the real one.

## Example

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;Description=ABC transporter
```

biolint reports:

```text
warning[GFF206]: attribute `Description` starts with an upper-case letter but is not a tag the specification defines
 --> example.gff3:2:44
  |
2 | chr1→example→gene→2100→7400→.→+→.→ID=gene1;Description=ABC transporter
  |                                            ^^^^^^^^^^^
  = help: rename it to start with a lower-case letter, e.g. `description`; upper-case initials are reserved for ID, Name, Alias, Parent and the other defined tags
  = spec: GFF3 1.26, Column 9: "attributes"
```

In these listings `→` stands for a tab.

## Accepted

```text
##gff-version 3
chr1→example→gene→2100→7400→.→+→.→ID=gene1;description=ABC transporter
```

## Configuration

Silence it with `--ignore GFF206`, or check only this rule with `--select GFF206`.
