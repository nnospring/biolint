# BED041: blockSizes or blockStarts is not a comma-separated list of integers

| | |
|---|---|
| Name | `block-list-malformed` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.9 |

Both lists are non-negative whole numbers separated by commas, with no spaces; one comma after the last number is allowed. A negative size, a different separator, or a missing comma between two numbers makes the list unreadable.

## Example

```text
chr22→1000→5000→cloneA→960→+→1000→5000→0→2→567;488→0,3512
```

biolint reports:

```text
error[BED041]: blockSizes `567;488` uses `;` between values
 --> example.bed:1:47
  |
1 | chr22→1000→5000→cloneA→960→+→1000→5000→0→2→567;488→0,3512
  |                                               ^
  = help: separate the values with commas only, without spaces
  = note: column 11 is read as blockSizes because the columns to its right on this line fit the standard fields that follow it; if column 11 is a custom field instead, declare it with `--option bed.type=bed9+3`
  = spec: BED v1.0 §1.9
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED041`, or check only this rule with `--select BED041`.
