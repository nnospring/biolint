# VCF301: INFO is not a list of key[=value] entries

| | |
|---|---|
| Name | `info-malformed` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

INFO is `.` or semicolon-separated `key` / `key=value` entries. An entry without a key (`=5`), or a key with characters outside `[A-Za-z0-9_.]`, cannot be parsed reliably.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→=5
```

biolint reports:

```text
error[VCF301]: INFO entry `=5` has no key before `=`
 --> example.vcf:3:17
  |
3 | 1→100→.→A→T→.→.→=5
  |                 ^^
  = help: entries are `KEY=value` or a bare `FLAG`
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF301`, or check only this rule with `--select VCF301`.
