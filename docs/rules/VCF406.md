# VCF406: Number of sample values does not match the declaration

| | |
|---|---|
| Name | `sample-count` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.4.2 |

As for INFO: `A` is one value per ALT allele, `R` one per allele, `G` one per possible genotype given the sample's ploidy. Mismatches arise when alleles were split, merged or trimmed without updating `AD`/`PL`.

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=AD,Number=R,Type=Integer,Description="Allelic depths">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT:AD→0/1:10
```

biolint reports:

```text
warning[VCF406]: `AD` has 1 value but its declaration requires one per allele including REF (2)
 --> example.vcf:5:29
  |
5 | 1→100→.→A→T→.→.→.→GT:AD→0/1:10
  |                             ^^
  = help: per-allele values must be updated whenever alleles are split, merged or removed (`bcftools norm` does this for declared tags)
  = note: declared as Number=R,Type=Integer on line 3
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF406`, or check only this rule with `--select VCF406`.
