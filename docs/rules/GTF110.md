# GTF110: Line of a feature type outside GTF 2.2 has no transcript_id

| | |
|---|---|
| Name | `gene-line-without-transcript-id` |
| Format | GTF |
| Level | `off` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

GTF 2.2 requires both `gene_id` and `transcript_id` on every line and writes `transcript_id "";` when a feature belongs to no transcript. Ensembl and GENCODE `gene` lines have no `transcript_id` at all, and the tools in common use accept that, so the default profile does not report it. A file that must satisfy a GTF 2.2 parser needs `transcript_id "";` on those lines.

## Example

```text
chr1→example→gene→1200→2100→.→+→.→gene_id "g1"; gene_name "ABC1";
chr1→example→exon→1200→2100→.→+→.→gene_id "g1"; transcript_id "g1.t1";
```

biolint reports:

```text
error[GTF110]: the gene line has no `transcript_id` attribute
 --> example.gtf:1:35
  |
1 | chr1→example→gene→1200→2100→.→+→.→gene_id "g1"; gene_name "ABC1";
  |                                   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: GTF 2.2 requires it on every line: write `transcript_id "";` when the feature belongs to no transcript
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF110`, or check only this rule with `--select GTF110`.
