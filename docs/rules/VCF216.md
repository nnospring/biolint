# VCF216: Invalid FILTER

| | |
|---|---|
| Name | `filter-invalid` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.1 |

FILTER is `PASS`, `.`, or a semicolon-separated list of filter names without whitespace, empty entries or repeats. `0` is reserved, and `PASS` cannot be combined with failed filters.

## Example

```text
##fileformat=VCFv4.3
##FILTER=<ID=q10,Description="Quality below 10">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→PASS;q10→.
```

biolint reports:

```text
error[VCF216]: `PASS` cannot be combined with failed filters
 --> example.vcf:4:15
  |
4 | 1→100→.→A→T→.→PASS;q10→.
  |               ^^^^
  = help: list only the filters that failed
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF216`, or check only this rule with `--select VCF216`.
