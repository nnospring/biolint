# GFF202: Attributes are written in GTF/GFF2 style

| | |
|---|---|
| Name | `gtf-style-attributes` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Column 9: "attributes" |

This line writes its attributes as `gene_id "X"; transcript_id "Y";`, which is the GTF (GFF version 2) convention. GFF3 writes `ID=X;Parent=Y`. The two formats share the first eight columns and often the `.gff` extension, but a GFF3 parser finds no ID or Parent in such a file and loses the gene structure. If the file is meant to be GTF, rename it to `.gtf` (or check it with `--type gtf`); to get GFF3, convert it with `gffread in.gtf -o out.gff3` or `agat_convert_sp_gxf2gxf.pl`.

## Example

```text
##gff-version 3
chr1→example→exon→2100→2600→.→+→.→gene_id "gene1"; transcript_id "tx1";
```

biolint reports:

```text
error[GFF202]: attributes are written as `gene_id "gene1";`, the GTF/GFF2 style, not as `tag=value`
 --> example.gff3:2:35
  |
2 | chr1→example→exon→2100→2600→.→+→.→gene_id "gene1"; transcript_id "tx1";
  |                                   ^^^^^^^^^^^^^^^
  = help: the file is GTF or GFF2, not GFF3: check it with `--type gtf`, or convert it with `gffread in.gtf -o out.gff3`
  = spec: GFF3 1.26, Column 9: "attributes"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF202`, or check only this rule with `--select GFF202`.
