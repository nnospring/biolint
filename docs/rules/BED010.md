# BED010: Line has fewer than three fields

| | |
|---|---|
| Name | `too-few-fields` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.5 |

Every data line needs at least a chromosome, a start and an end. A line with one or two fields usually means the file is separated by something other than tabs (commas, semicolons), or that it lists regions as `chr1:1000-5000`, which is a different notation with different coordinates.

## Example

A region string, not BED:

```text
chr1:1001-5000
```

biolint reports:

```text
error[BED010]: line has 1 field; a BED line needs at least 3 (chrom, chromStart, chromEnd)
 --> example.bed:1:1
  |
1 | chr1:1001-5000
  | ^^^^^^^^^^^^^^
  = help: this is a region string, which counts from 1; the same interval in BED is `chr1\t1000\t5000`
  = spec: BED v1.0 §1.5
```

Comma-separated:

```text
chr1,1000,5000
```

biolint reports:

```text
error[BED010]: line has 1 field; a BED line needs at least 3 (chrom, chromStart, chromEnd)
 --> example.bed:1:1
  |
1 | chr1,1000,5000
  | ^^^^^^^^^^^^^^
  = help: the file is comma-separated (CSV); BED needs tabs: export as tab-separated text, or `tr ',' '\t' < file.csv > file.bed` if no value contains a comma
  = spec: BED v1.0 §1.5
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED010`, or check only this rule with `--select BED010`.
