# FQ010: Read has no bases

| | |
|---|---|
| Name | `empty-read` |
| Format | FASTQ |
| Level | `warning` |
| Source | Cock et al. 2010 (NAR 38:1767), "FASTQ definition" |

The sequence and quality lines are empty. The format permits a zero-length read, and adapter trimmers produce them when a read is all adapter, but some aligners and assemblers stop on one. Drop them when trimming (`cutadapt -m 1`, `fastp -l 1`) and keep paired files in step (`cutadapt` and `fastp` do this when given both files).

## Example

The first read is empty:

```text
@read1

+

@read2
ACGT
+
IIII
```

biolint reports:

```text
warning[FQ010]: read `read1` has no bases
 --> example.fastq:2
  = help: drop zero-length reads when trimming (`cutadapt -m 1`, `fastp -l 1`); some aligners stop on them
  = spec: Cock et al. 2010 (NAR 38:1767), "FASTQ definition"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FQ010`, or check only this rule with `--select FQ010`.
