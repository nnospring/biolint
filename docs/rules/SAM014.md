# SAM014: Alternative reference name (AN) is malformed or not distinct

| | |
|---|---|
| Name | `sq-alt-name-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

`AN` is a comma-separated list of other names for the same sequence. Each follows the reference-name rules, and all `SN` and `AN` names in the header must differ from one another; otherwise a request for that name is ambiguous. samtools warns about the clash.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→AN:1
@SQ→SN:chr2→LN:900→AN:2,1
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM014]: alternative name `1` is listed twice
 --> example.sam:3:25
  |
3 | @SQ→SN:chr2→LN:900→AN:2,1
  |                         ^
  = help: each alias may name one reference only
  = note: first listed on line 2
  = spec: SAM v1 §1.3
```

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000→AN:=
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM014]: alternative name `=` starts with `=`
 --> example.sam:2:24
  |
2 | @SQ→SN:chr1→LN:1000→AN:=
  |                        ^
  = help: alternative names follow the same rules as `SN`; separate several with commas
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:MT→LN:16569→AN:chrMT,M,chrM→TP:circular
r1→0→MT→10→30→5M→*→0→0→ACGTA→IIIII
```

## Configuration

Silence it with `--ignore SAM014`, or check only this rule with `--select SAM014`.
