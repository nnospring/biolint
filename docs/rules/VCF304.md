# VCF304: INFO key is not declared in the header

| | |
|---|---|
| Name | `info-undeclared` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.4.2 |

Each INFO key should have a `##INFO=<ID=...>` line. Without it, htslib assumes `Number=1,Type=String` and warns, BCF conversion fails, and type-aware filtering (`INFO/X > 5`) stops working. Reported once per key.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
warning[VCF304]: INFO key `DP` has no `##INFO` line
 --> example.vcf:3:17
  |
3 | 1→100→.→A→T→.→.→DP=3
  |                 ^^
  = help: add `##INFO=<ID=DP,Number=1,Type=Integer,Description="...">` to the header
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF304`, or check only this rule with `--select VCF304`.
