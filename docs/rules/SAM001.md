# SAM001: @HD is not the first line, or appears twice

| | |
|---|---|
| Name | `hd-not-first` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.3 |

A file has at most one `@HD` line and it is the very first line. A second `@HD`, or one that follows `@SQ` lines, usually means two headers were pasted together or lines were reordered by `sort` or `grep`. samtools reads such a file; biolint takes the sort order from the first `@HD` line.

## Example

@HD after @SQ:

```text
@SQ→SN:chr1→LN:1000
@HD→VN:1.6→SO:unsorted
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM001]: `@HD` is on line 2; it must be the first line of the file
 --> example.sam:2:1
  |
2 | @HD→VN:1.6→SO:unsorted
  | ^^^
  = help: move it to the top
  = spec: SAM v1 §1.3
```

Two @HD lines:

```text
@HD→VN:1.6→SO:unsorted
@HD→VN:1.6→SO:coordinate
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM001]: a second `@HD` line
 --> example.sam:2:1
  |
2 | @HD→VN:1.6→SO:coordinate
  | ^^^
  = help: keep one `@HD` line, as the first line of the file
  = spec: SAM v1 §1.3
```

In these listings `→` stands for a tab.

## Accepted

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

## Configuration

Silence it with `--ignore SAM001`, or check only this rule with `--select SAM001`.
