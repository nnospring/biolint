# GTF105: Quoted value is never closed

| | |
|---|---|
| Name | `unclosed-quote` |
| Format | GTF |
| Level | `error` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

A value that begins with a double quote must end with one. When the closing quote is missing, the rest of the line, including the following attributes, becomes part of the value.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1;
```

biolint reports:

```text
error[GTF105]: the quoted value of `transcript_id` is never closed
 --> example.gtf:1:63
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1;
  |                                                               ^
  = help: add the closing `"` before the semicolon
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF105`, or check only this rule with `--select GTF105`.
