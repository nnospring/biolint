# VCF409: FORMAT key is not alphanumeric (VCF 4.1/4.2)

| | |
|---|---|
| Name | `format-key-legacy` |
| Format | VCF |
| Level | `off` by default, `error` with `--strict` |
| Source | VCF 4.2 §1.4.2 |

VCF 4.1 and 4.2 describe FORMAT keys as alphanumeric; `_` and `.` became legal in 4.3. Keys such as GATK's `MIN_DP` in files that declare 4.1/4.2 are accepted by every mainstream parser, so this is reported in strict mode only.

## Example

```text
##fileformat=VCFv4.2
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=MIN_DP,Number=1,Type=Integer,Description="Minimum depth in the block">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT:MIN_DP→0/1:5
```

biolint reports:

```text
error[VCF409]: FORMAT key `MIN_DP` contains `_`, which VCF 4.2 does not allow
 --> example.vcf:5:22
  |
5 | 1→100→.→A→T→.→.→.→GT:MIN_DP→0/1:5
  |                      ^^^^^^
  = help: declare `##fileformat=VCFv4.3` (which allows `_` and `.` in keys), or rename the key
  = spec: VCF 4.2 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF409`, or check only this rule with `--select VCF409`.
