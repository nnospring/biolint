# VCF015: Meta-information line after the column header

| | |
|---|---|
| Name | `meta-after-header` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4 |

All `##` lines must come before the `#CHROM` line. A `##` line further down is what `cat a.vcf b.vcf` produces: use `bcftools concat` or `bcftools merge`, which reconcile the headers.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
##source=second_file
1→200→.→G→C→.→.→.
```

biolint reports:

```text
error[VCF015]: meta-information line after the `#CHROM` header line
 --> example.vcf:4:1
  |
4 | ##source=second_file
  | ^^
  = help: move all `##` lines above the `#CHROM` line; to join files use `bcftools concat`, not `cat`
  = note: the column header is on line 2
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF015`, or check only this rule with `--select VCF015`.
