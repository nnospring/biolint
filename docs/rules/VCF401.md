# VCF401: Invalid FORMAT column

| | |
|---|---|
| Name | `format-malformed` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6.2 |

FORMAT is a colon-separated list of keys matching `[A-Za-z_][0-9A-Za-z_.]*`, with no empty or repeated key.

## Example

```text
##fileformat=VCFv4.3
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=DP,Number=1,Type=Integer,Description="Read depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO→FORMAT→S1
1→100→.→A→T→.→.→.→GT:DP:DP→0/1:5:5
```

biolint reports:

```text
error[VCF401]: FORMAT key `DP` is listed twice
 --> example.vcf:5:25
  |
5 | 1→100→.→A→T→.→.→.→GT:DP:DP→0/1:5:5
  |                         ^^
  = help: remove the repeated key and its values in every sample
  = spec: VCF 4.3 §1.6.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF401`, or check only this rule with `--select VCF401`.
