# BED031: Name is longer than 255 characters

| | |
|---|---|
| Name | `name-too-long` |
| Format | BED |
| Level | `off` by default, `error` with `--strict` |
| Source | BED v1.0 §1.7 |

The specification limits the name to 255 characters. Tools generally accept longer names, so this is only checked in the strict profile; very long names usually mean that a whole annotation string was put in the name column.

## Example

```text
chr1→1000→5000→ACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGT
```

biolint reports:

```text
error[BED031]: name is 256 characters long; the limit is 255
 --> example.bed:1:16
  |
1 | chr1→1000→5000→ACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTACGTA…
  |                ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: shorten the name, or move the description to a custom column after the standard ones
  = note: column 4 is read as name because the columns to its right on this line fit the standard fields that follow it; if column 4 is a custom field instead, declare it with `--option bed.type=bed3+1`
  = spec: BED v1.0 §1.7
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED031`, or check only this rule with `--select BED031`.
