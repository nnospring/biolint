# VCF012: Description is not a quoted string

| | |
|---|---|
| Name | `meta-description-unquoted` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.4.2 |

The Description must be surrounded by double quotes. Unquoted text is cut at the first comma by most parsers, and bcftools rewrites such headers with a warning.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description=Total depth>
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3
```

biolint reports:

```text
warning[VCF012]: Description must be in double quotes
 --> example.vcf:2:49
  |
2 | ##INFO=<ID=DP,Number=1,Type=Integer,Description=Total depth>
  |                                                 ^^^^^^^^^^^
  = help: write `Description="Total depth"`
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF012`, or check only this rule with `--select VCF012`.
