# FA005: Blank line inside a sequence

| | |
|---|---|
| Name | `blank-line-in-sequence` |
| Format | FASTA |
| Level | `error` |
| Source | NCBI BLAST help, FASTA ("Blank lines are not allowed in the middle of FASTA input"); faidx(5) |

An empty line sits between two sequence lines of the same record. `samtools faidx` cannot index the file, and several parsers treat the blank line as the end of the record and discard the rest of the sequence. Delete the blank line; if the lines after it belong to a new record, its `>` header is missing.

## Example

```text
>seq1
ACGTACGT

ACGTACGT
```

biolint reports:

```text
error[FA005]: 1 blank line inside the sequence of `seq1`
 --> example.fasta:3
  = help: delete the blank line; if a new record starts after it, its `>` header line is missing
  = spec: NCBI BLAST help, FASTA ("Blank lines are not allowed in the middle of FASTA input"); faidx(5)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA005`, or check only this rule with `--select FA005`.
