# BED036: thickStart or thickEnd is not a non-negative integer

| | |
|---|---|
| Name | `thick-invalid` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.8 |

thickStart and thickEnd are positions on the chromosome, written like chromStart and chromEnd: digits only. They mark the part of the feature drawn thick (the coding region of a transcript). When there is no such part, repeat chromStart in both columns.

## Example

```text
chr1→1000→5000→geneA→0→+→1200→4800
chr1→7000→7250→geneB→0→-→7e3→7250
```

biolint reports:

```text
error[BED036]: thickStart `7e3` is in scientific notation
 --> example.bed:2:26
  |
2 | chr1→7000→7250→geneB→0→-→7e3→7250
  |                          ^^^
  = help: write `7000`; R writes round numbers this way (`1e+05` for 100000): set `options(scipen = 999)` before `write.table`, or use `format(x, scientific = FALSE)`. Spreadsheets do the same to large numbers: format the column as a number without exponent
  = note: 8 fields per line, all read as standard fields (BED8, inferred from line 1); if column 7 is a custom field instead, declare it with `--option bed.type=bed6+2`
  = spec: BED v1.0 §1.8
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED036`, or check only this rule with `--select BED036`.
