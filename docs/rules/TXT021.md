# TXT021: File name suggests a different format than the content

| | |
|---|---|
| Name | `extension-mismatch` |
| Format | Any format |
| Level | `warning` |

The extension belongs to one format but the content clearly is another (for example GTF saved as `.gff3`, or FASTQ saved as `.fasta`). biolint checks the file as what it contains. Rename the file, or pass `--type` to force a format.

## Configuration

Silence it with `--ignore TXT021`, or check only this rule with `--select TXT021`.
