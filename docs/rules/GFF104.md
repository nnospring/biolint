# GFF104: Sequence ID contains whitespace

| | |
|---|---|
| Name | `seqid-invalid` |
| Format | GFF3 |
| Level | `error` |
| Source | GFF3 1.26, Column 1: "seqid" |

The first column names the sequence the feature is on, and it may not contain unescaped whitespace. FASTA readers cut a sequence name at the first space, so a seqid such as `chr1 Homo sapiens` never matches the sequence `chr1` and every feature on it is dropped by tools that join annotation and sequence.

## Example

```text
##gff-version 3
chr1 Homo sapiens→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
error[GFF104]: seqid `chr1 Homo sapiens` contains a space
 --> example.gff3:2:5
  |
2 | chr1 Homo sapiens→example→gene→2100→7400→.→+→.→ID=gene1
  |     ^
  = help: use the sequence name up to the first space (`chr1`), as FASTA readers do, or write the space as `%20`
  = spec: GFF3 1.26, Column 1: "seqid"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF104`, or check only this rule with `--select GFF104`.
