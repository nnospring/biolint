# VCF307: Flag has a value, or a non-Flag key has none

| | |
|---|---|
| Name | `info-flag-value` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.4.2 |

A `Flag` is present or absent and takes no `=value`. A key of any other type needs a value; a bare key is read as a flag and its declared type is ignored.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP
```

biolint reports:

```text
warning[VCF307]: `DP` is declared as Integer but has no value here
 --> example.vcf:4:17
  |
4 | 1→100→.→A→T→.→.→DP
  |                 ^^
  = help: write `DP=<value>`, or `DP=.` if it is missing
  = note: declared on line 2
  = spec: VCF 4.3 §1.4.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF307`, or check only this rule with `--select VCF307`.
