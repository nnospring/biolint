# TXT014: Last line is not terminated, which this format requires

| | |
|---|---|
| Name | `final-newline-required` |
| Format | Any format |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.6 |
| Fixable | yes, with `biolint --fix` |

Reported instead of TXT009 for formats whose specification says the last line must end with a line separator (VCF 4.3 and later: "the last data line must end with a line separator"). Parsers generally cope, but the file does not conform, and a missing terminator is also what a truncated file looks like.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[TXT014]: the last line is not terminated by a newline
 --> example.vcf:3
  = help: append a newline; if the file should be longer, it may be truncated
  = fix: Add a final newline (--fix)
  = spec: VCF 4.3 §1.6
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore TXT014`, or check only this rule with `--select TXT014`.
