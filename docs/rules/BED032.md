# BED032: Name looks like a gene symbol converted to a date by a spreadsheet

| | |
|---|---|
| Name | `name-excel-date` |
| Format | BED |
| Level | `warning` |

Excel and other spreadsheets silently turn gene symbols into dates: MARCH1 becomes `1-Mar`, SEPT2 becomes `2-Sep`, DEC1 becomes `1-Dec`, and RIKEN identifiers such as 2310009E13 become `2.31E+13`. About a fifth of papers with supplementary gene lists were found to contain such errors (Ziemann, Eren and El-Osta, Genome Biology 2016). The original symbol cannot be recovered from the file: go back to the source and import the column as text. To keep false alarms low, only names that are *entirely* a day-month or month-year pair in the exact form spreadsheets write (`1-Mar`, `Sep-07`), or a three-digit mantissa with exponent (`2.31E+13`), are reported.

## Example

```text
chr1→1000→5000→1-Mar→0→+
```

biolint reports:

```text
warning[BED032]: name `1-Mar` looks like a gene symbol that a spreadsheet turned into a date (probably `MARCH1` or `MARC1`)
 --> example.bed:1:16
  |
1 | chr1→1000→5000→1-Mar→0→+
  |                ^^^^^
  = help: the original symbol cannot be recovered from this file: go back to the source and import the column as text (current HGNC symbols such as MARCHF1 and SEPTIN2 avoid the problem)
  = note: column 4 is read as name because the columns to its right on this line fit the standard fields that follow it; if column 4 is a custom field instead, declare it with `--option bed.type=bed3+3`
```

```text
chr2→1000→5000→Sep-07→0→-
```

biolint reports:

```text
warning[BED032]: name `Sep-07` looks like a gene symbol that a spreadsheet turned into a date
 --> example.bed:1:16
  |
1 | chr2→1000→5000→Sep-07→0→-
  |                ^^^^^^
  = help: the original symbol cannot be recovered from this file: go back to the source and import the column as text (current HGNC symbols such as MARCHF1 and SEPTIN2 avoid the problem)
  = note: column 4 is read as name because the columns to its right on this line fit the standard fields that follow it; if column 4 is a custom field instead, declare it with `--option bed.type=bed3+3`
```

In these listings `→` stands for a tab.

## Accepted

```text
chr1→1000→5000→MARCHF1→0→+
chr1→7000→7250→Mar-A-Lago→0→+
```

## Configuration

Silence it with `--ignore BED032`, or check only this rule with `--select BED032`.
