# VCF501: Duplicate record

| | |
|---|---|
| Name | `duplicate-record` |
| Format | VCF |
| Level | `warning` |
| Source | VCF 4.3 §1.6.1 |

Two records have the same CHROM, POS, REF and ALT. Duplicates double-count in downstream statistics and usually come from concatenating overlapping chunks. Remove with `bcftools norm -d exact`.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
1→100→.→A→T→.→.→.
```

biolint reports:

```text
warning[VCF501]: duplicate record: `1`:100 A>T already appeared
 --> example.vcf:4:1
  |
4 | 1→100→.→A→T→.→.→.
  | ^^^^^^^^^^^
  = help: remove exact duplicates with `bcftools norm -d exact`
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF501`, or check only this rule with `--select VCF501`.
