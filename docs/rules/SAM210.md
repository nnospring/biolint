# SAM210: PG tag names a program the header does not define

| | |
|---|---|
| Name | `pg-undeclared` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAMtags §1.2 |

When the header has `@PG` lines, the value of a `PG:Z:` tag is the `ID` of one of them: it says which program produced the record. An unknown ID usually means the header was replaced or the `@PG` lines were filtered out.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
@PG→ID:bwa→PN:bwa
r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→PG:Z:bowtie2
```

biolint reports:

```text
warning[SAM210]: program `bowtie2` is not defined by any @PG line
 --> example.sam:4:43
  |
4 | r1→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII→PG:Z:bowtie2
  |                                           ^^^^^^^
  = help: add an @PG line with `ID:bowtie2`, or remove the tag
  = spec: SAMtags §1.2
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM210`, or check only this rule with `--select SAM210`.
