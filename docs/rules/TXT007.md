# TXT007: Control character in text

| | |
|---|---|
| Name | `control-character` |
| Format | Any format |
| Level | `error` |

A NUL or other control character appears in the text. NUL bytes usually mean the file is binary, was preallocated and never fully written, or was corrupted in transfer.

## Example

```text
>seq1
AC␀GT
```

biolint reports:

```text
error[TXT007]: NUL byte in text
 --> example.fasta:2:3
  |
2 | AC␦GT
  |   ^
  = help: NUL bytes usually mean a binary, corrupted or partly written file
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore TXT007`, or check only this rule with `--select TXT007`.
