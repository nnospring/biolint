# GTF106: Text value is not in double quotes

| | |
|---|---|
| Name | `unquoted-value` |
| Format | GTF |
| Level | `warning` by default, `error` with `--strict` |
| Source | GTF 2.2, GTF Field Definitions: [attributes] |

Values that are text are written in double quotes: `gene_id "g1";`. Numbers may stand alone, as in GENCODE's `level 2;`. HTSeq accepts unquoted text, but RSEM stops when `gene_id` or `transcript_id` is not quoted, and an unquoted value cannot contain a space.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id g1; transcript_id g1.t1;
```

biolint reports:

```text
warning[GTF106]: the value `g1` of `gene_id` is not in double quotes
 --> example.gtf:1:43
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id g1; transcript_id g1.t1;
  |                                           ^^
  = help: write `gene_id "g1";`
  = spec: GTF 2.2, GTF Field Definitions: [attributes]

warning[GTF106]: the value `g1.t1` of `transcript_id` is not in double quotes
 --> example.gtf:1:61
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id g1; transcript_id g1.t1;
  |                                                             ^^^^^
  = help: write `transcript_id "g1.t1";`
  = spec: GTF 2.2, GTF Field Definitions: [attributes]
```

In these listings `→` stands for a tab.

## Accepted

```text
#!genome-build GRCh38.p14
1→havana→gene→1000→9000→.→-→.→gene_id "ENSG01"; gene_version "2"; gene_name "ABC1"; gene_biotype "protein_coding";
1→havana→transcript→1000→9000→.→-→.→gene_id "ENSG01"; gene_version "2"; transcript_id "ENST01"; gene_name "ABC1"; tag "basic"; tag "CCDS";
1→havana→exon→8000→9000→.→-→.→gene_id "ENSG01"; gene_version "2"; transcript_id "ENST01"; exon_number 1; gene_name "ABC1";
1→havana→CDS→8000→8600→.→-→0→gene_id "ENSG01"; gene_version "2"; transcript_id "ENST01"; exon_number 1; gene_name "ABC1";
1→havana→start_codon→8598→8600→.→-→0→gene_id "ENSG01"; gene_version "2"; transcript_id "ENST01"; exon_number 1; gene_name "ABC1";
1→havana→five_prime_utr→8601→9000→.→-→.→gene_id "ENSG01"; gene_version "2"; transcript_id "ENST01"; gene_name "ABC1";
1→havana→exon→1000→2000→.→-→.→gene_id "ENSG01"; gene_version "2"; transcript_id "ENST01"; exon_number 2; gene_name "ABC1";
```

## Configuration

Silence it with `--ignore GTF106`, or check only this rule with `--select GTF106`.
