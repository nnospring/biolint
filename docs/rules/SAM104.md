# SAM104: Read name is longer than 254 characters

| | |
|---|---|
| Name | `qname-too-long` |
| Format | SAM |
| Level | `error` |
| Source | SAM v1 §1.4 |

Read names are limited to 254 characters because BAM stores the length in one byte. samtools stops with "query name too long". Shorten the names before alignment, for example by dropping the FASTQ comment.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
rrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrr→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
error[SAM104]: read name is 255 characters long; the limit is 254
 --> example.sam:3:255
  |
3 | …rrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrrr→0→chr1→10→30→5M→*→0→0→ACGTA→IIIII
  |                                                                                                                               ^
  = help: shorten the read names before aligning, e.g. drop the FASTQ comment or replace long names with a counter
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM104`, or check only this rule with `--select SAM104`.
