# GZ003: Compressed with plain gzip, not BGZF

| | |
|---|---|
| Name | `gzip-not-bgzf` |
| Format | Any format |
| Level | `info` |

The file is ordinary gzip. That is readable everywhere, but tabix, `samtools faidx` and `bcftools index` need BGZF (block gzip) to seek. Recompress with `zcat file.gz | bgzip > file.bgz` if you plan to index it.

## Configuration

Silence it with `--ignore GZ003`, or check only this rule with `--select GZ003`.
