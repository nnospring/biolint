# SAM107: RNAME or RNEXT contains a forbidden character

| | |
|---|---|
| Name | `rname-invalid` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.2.1 |

RNAME and RNEXT follow the same rules as `@SQ SN`: printable ASCII without spaces, backslashes, commas, quotation marks or brackets, not starting with `*` or `=`. (`*` alone means "none", and `=` alone in RNEXT means "same as RNAME".) samtools keeps such names; region strings and the `SA` tag cannot express them.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1,alt→LN:1000
r1→0→chr1,alt→10→30→5M→*→0→0→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM107]: RNAME `chr1,alt` contains `,`
 --> example.sam:3:10
  |
3 | r1→0→chr1,alt→10→30→5M→*→0→0→ACGTA→IIIII
  |          ^
  = help: rename the sequence in the reference FASTA and realign, or rename it here and in every record with `samtools reheader`
  = spec: SAM v1 §1.2.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM107`, or check only this rule with `--select SAM107`.
