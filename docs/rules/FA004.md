# FA004: Record has no sequence

| | |
|---|---|
| Name | `sequence-empty` |
| Format | FASTA |
| Level | `warning` by default, `error` with `--strict` |
| Source | NCBI BLAST help, FASTA; faidx(5) |

A header is followed directly by the next header or by the end of the file. `samtools faidx` leaves such a record out of the index without a message, or fails with "File truncated" when it is the last record, and many other tools reject or skip zero-length sequences. It usually means an upstream step produced nothing for this entry, or a header line was duplicated.

## Example

```text
>seq1
>seq2
ACGTACGT
```

biolint reports:

```text
warning[FA004]: record `seq1` has no sequence
 --> example.fasta:1
  = help: remove the header, or restore the missing sequence; `seqkit seq -m 1` drops empty records
  = spec: NCBI BLAST help, FASTA; faidx(5)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA004`, or check only this rule with `--select FA004`.
