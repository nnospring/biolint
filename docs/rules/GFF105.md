# GFF105: Sequence ID contains a character that must be escaped

| | |
|---|---|
| Name | `seqid-characters` |
| Format | GFF3 |
| Level | `warning` by default, `error` with `--strict` |
| Source | GFF3 1.26, Column 1: "seqid" |

A seqid may contain letters, digits and `. : ^ * $ @ ! + _ ? - |`; any other character has to be percent-encoded (a comma as `%2C`, for example). Tools generally accept other characters, but names with `,`, `;`, `=`, `/` or parentheses break region strings, file names derived from sequence names, and tabix queries.

## Example

```text
##gff-version 3
scaffold(12)→example→gene→2100→7400→.→+→.→ID=gene1
```

biolint reports:

```text
warning[GFF105]: seqid `scaffold(12)` contains `(`, which must be percent-encoded
 --> example.gff3:2:9
  |
2 | scaffold(12)→example→gene→2100→7400→.→+→.→ID=gene1
  |         ^
  = help: write it as `%28`, or rename the sequence here and in the FASTA file; unescaped, a seqid may hold letters, digits and `.:^*$@!+_?-|`
  = spec: GFF3 1.26, Column 1: "seqid"
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GFF105`, or check only this rule with `--select GFF105`.
