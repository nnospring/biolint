# GTF002: Line ends with an extra tab

| | |
|---|---|
| Name | `trailing-tab` |
| Format | GTF |
| Level | `warning` by default, `error` with `--strict` |
| Source | GTF 2.2, Introduction |

A tab after the attributes creates an empty tenth column. Most parsers ignore it; those that count columns reject the line. Scripts that append a tab to every field produce it.

## Example

```text
chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";→
```

biolint reports:

```text
warning[GTF002]: the line ends with a tab after the attributes column
 --> example.gtf:1:71
  |
1 | chr1→example→exon→1200→1350→.→+→.→gene_id "g1"; transcript_id "g1.t1";→
  |                                                                       ^
  = help: remove the trailing tab
  = spec: GTF 2.2, Introduction
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore GTF002`, or check only this rule with `--select GTF002`.
