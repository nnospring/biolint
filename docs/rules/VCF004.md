# VCF004: Meta-information line is not ##key=value

| | |
|---|---|
| Name | `meta-malformed` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.4 |

Lines before the column header must start with `##` and have the form `##key=value` with a non-empty key and value. A line that lost its `##` (or gained a stray space) is read as a data line and derails parsing.

## Example

```text
##fileformat=VCFv4.3
##source
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→.
```

biolint reports:

```text
error[VCF004]: meta-information line has no `=`
 --> example.vcf:2:1
  |
2 | ##source
  | ^^^^^^^^
  = help: the form is `##key=value`
  = spec: VCF 4.3 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF004`, or check only this rule with `--select VCF004`.
