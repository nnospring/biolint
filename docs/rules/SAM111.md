# SAM111: POS, PNEXT or TLEN does not fit in 32 bits

| | |
|---|---|
| Name | `coordinate-range` |
| Format | SAM |
| Level | `warning` by default, `error` with `--strict` |
| Source | SAM v1 §1.4 |

POS and PNEXT may be at most 2^31-1 (2,147,483,647) and TLEN lies between -(2^31-1) and 2^31-1. samtools reads larger values from SAM text, but they cannot be stored in BAM, and no reference allowed by the specification is that long.

## Example

```text
@HD→VN:1.6→SO:unsorted
@SQ→SN:chr1→LN:1000
r1→0→chr1→10→30→5M→*→0→3000000000→ACGTA→IIIII
```

biolint reports:

```text
warning[SAM111]: TLEN 3000000000 is outside -2147483647..2147483647
 --> example.sam:3:24
  |
3 | r1→0→chr1→10→30→5M→*→0→3000000000→ACGTA→IIIII
  |                        ^^^^^^^^^^
  = help: a template cannot be longer than the longest reference; write 0 when the template length is unknown
  = spec: SAM v1 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore SAM111`, or check only this rule with `--select SAM111`.
