# FA010: Whitespace inside a sequence line

| | |
|---|---|
| Name | `sequence-whitespace` |
| Format | FASTA |
| Level | `error` |
| Source | NCBI BLAST help, FASTA; faidx(5) |

A sequence line contains spaces or tabs. An index made by `samtools faidx` counts only the visible characters but seeks by byte, so regions fetched from such a file are shifted; other tools count the spaces as residues or stop. Sequences copied from a web page or a document often come in blocks of ten separated by spaces. Remove them: `sed -i '/^>/! s/[ \t]//g' file.fa`.

## Example

Blocks of ten separated by spaces:

```text
>seq1
ACGTACGTAC GTACGTACGT ACGTACGTAC
```

biolint reports:

```text
error[FA010]: 2 whitespace characters inside the sequence line
 --> example.fasta:2:11
  |
2 | ACGTACGTAC GTACGTACGT ACGTACGTAC
  |           ^
  = help: remove spaces and tabs from the sequence lines: `sed -i '/^>/! s/[ \t]//g' file.fa`
  = spec: NCBI BLAST help, FASTA; faidx(5)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA010`, or check only this rule with `--select FA010`.
