# BED006: Line starts with a space or tab

| | |
|---|---|
| Name | `leading-whitespace` |
| Format | BED |
| Level | `error` |
| Source | BED v1.0 §1.4 |

A data line starts with the chromosome name and a comment starts with `#`, in the first column in both cases. With whitespace in front, tab-based parsers read an empty chromosome name and every field is shifted by one column; an indented `#` line is not a comment at all. Indentation usually comes from pasting out of a document or e-mail.

## Example

```text
chr1→1000→5000
→chr1→7000→7250
```

biolint reports:

```text
error[BED006]: line starts with a tab, so the chromosome name is empty
 --> example.bed:2:1
  |
2 | →chr1→7000→7250
  | ^
  = help: delete the whitespace at the start of the line
  = spec: BED v1.0 §1.4
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore BED006`, or check only this rule with `--select BED006`.
