# VCF202: Empty field

| | |
|---|---|
| Name | `empty-field` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.6 |

No field may be empty: a missing value is written as `.`. Empty fields appear when a spreadsheet export drops the dot or when two tabs are adjacent.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→→A→T→.→.→.
```

biolint reports:

```text
error[VCF202]: ID field is empty
 --> example.vcf:3:7
  |
3 | 1→100→→A→T→.→.→.
  |       ^
  = help: write `.` for a missing value
  = spec: VCF 4.3 §1.6
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF202`, or check only this rule with `--select VCF202`.
