# VCF206: Records are not sorted by position

| | |
|---|---|
| Name | `unsorted` |
| Format | VCF |
| Level | `warning` by default, `error` with `--strict` |
| Source | VCF 4.3 §1.6.1 |

Within a CHROM, positions must be in increasing order. tabix and `bcftools index` fail on unsorted files ("unsorted positions"). Sort with `bcftools sort`.

## Example

```text
##fileformat=VCFv4.3
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→200→.→A→T→.→.→.
1→100→.→G→C→.→.→.
```

biolint reports:

```text
warning[VCF206]: position 100 comes after 200 on `1`
 --> example.vcf:4:3
  |
4 | 1→100→.→G→C→.→.→.
  |   ^^^
  = help: sort the file with `bcftools sort`
  = spec: VCF 4.3 §1.6.1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF206`, or check only this rule with `--select VCF206`.
