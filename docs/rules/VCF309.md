# VCF309: INFO END is before POS

| | |
|---|---|
| Name | `info-end-before-pos` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §3 |

`END` is the last reference position covered by the record, so it cannot be smaller than POS. htslib derives the record length from it; a negative length corrupts indexing ("END is smaller than POS").

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=END,Number=1,Type=Integer,Description="End position">
##ALT=<ID=DEL,Description="Deletion">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→500→.→A→<DEL>→.→.→END=100
```

biolint reports:

```text
error[VCF309]: END=100 is before POS 500
 --> example.vcf:5:21
  |
5 | 1→500→.→A→<DEL>→.→.→END=100
  |                     ^^^^^^^
  = help: END is the last reference base covered by the record, so END ≥ POS
  = spec: VCF 4.3 §3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF309`, or check only this rule with `--select VCF309`.
