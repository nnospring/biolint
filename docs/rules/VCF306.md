# VCF306: INFO value does not match the declared Type

| | |
|---|---|
| Name | `info-type` |
| Format | VCF |
| Level | `error` |
| Source | VCF 4.3 §1.3 |

An `Integer` must be a whole number, a `Float` a decimal/scientific number (or `inf`/`nan`), a `Character` a single character. Typical offenders: `NA`, `NaN` in an Integer, a decimal in an Integer field, or a decimal comma.

## Example

```text
##fileformat=VCFv4.3
##INFO=<ID=DP,Number=1,Type=Integer,Description="Total depth">
#CHROM→POS→ID→REF→ALT→QUAL→FILTER→INFO
1→100→.→A→T→.→.→DP=3.5
```

biolint reports:

```text
error[VCF306]: `DP` is declared as Integer but has the value `3.5`
 --> example.vcf:4:20
  |
4 | 1→100→.→A→T→.→.→DP=3.5
  |                    ^^^
  = help: round the value, or declare the key as `Type=Float`
  = note: declared on line 2
  = spec: VCF 4.3 §1.3
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore VCF306`, or check only this rule with `--select VCF306`.
