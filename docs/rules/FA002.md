# FA002: Header has no sequence identifier

| | |
|---|---|
| Name | `header-empty` |
| Format | FASTA |
| Level | `error` |
| Source | NCBI BLAST help, FASTA; faidx(5) |

The `>` must be followed by an identifier: the word up to the first space is how every tool names the sequence (the first column of a `.fai` index, the `@SQ SN` of an alignment, the subject of a BLAST hit). A bare `>` gives the record an empty name, so it cannot be fetched and clashes with every other unnamed record.

## Example

```text
>
ACGTACGT
```

biolint reports:

```text
error[FA002]: header is a bare `>` with no identifier
 --> example.fasta:1:1
  |
1 | >
  | ^
  = help: give the sequence a name: `>seq1 optional description`
  = spec: NCBI BLAST help, FASTA; faidx(5)
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FA002`, or check only this rule with `--select FA002`.
