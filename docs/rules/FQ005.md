# FQ005: Quality character outside the printable range

| | |
|---|---|
| Name | `quality-invalid-character` |
| Format | FASTQ |
| Level | `error` |
| Source | Cock et al. 2010 (NAR 38:1767), Table 1 |

Quality scores are stored as single printable ASCII characters, `!` (33) to `~` (126). A byte outside that range cannot be a score in any FASTQ variant: the file is damaged, was written in the wrong encoding, or is not text. (Spaces and tabs are reported as FQ011; other control characters by the generic rule TXT007.)

## Example

A non-ASCII character in the quality string:

```text
@read1
ACGTACGTA
+
IIIIéIII
```

biolint reports:

```text
error[FQ005]: `é` in the quality of read `read1` is not a quality character
 --> example.fastq:4:5
  |
4 | IIIIéIII
  |     ^
  = help: quality characters are the printable ASCII range `!` (33) to `~` (126); the file is damaged or was re-encoded
  = spec: Cock et al. 2010 (NAR 38:1767), Table 1
```

In these listings `→` stands for a tab.

## Configuration

Silence it with `--ignore FQ005`, or check only this rule with `--select FQ005`.
